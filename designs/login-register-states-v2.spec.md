# 用户端·登录/注册页（双状态）实现规格（对应 login-register-states-v2.png）

> 一图两屏总览：①验证码登录 ②密码登录。注册不占屏，收敛为底部小字链接（频率分层：高频占屏，低频入口）。
> token 事实源：`designs/UI-SPEC.md`；本 spec 与其同源，位图 dp 值以此处为准。

## 给前端的实现提示词（可直接复制）

实现移动端（iOS 视觉语言，原生 Compose 均可）的登录页，两个互斥子状态 + 一个注册入口，高保真还原附图。

- 整体布局：每屏 = 顶部蓝色渐变 Hero（含状态栏安全区、品牌名与柔和光效插画）→ 浅灰 `#F6F8FA` 滚动内容区（白色圆角卡片纵向排列，卡片 10dp 圆角、卡内 padding 16dp、页边距 16dp）→ 底部辅助链接行（含 Home Indicator 安全区）。
- 分段切换：卡内顶部"验证码登录 / 密码登录"分段控件，两文案与图完全一致；切换只换凭据行，骨架不动。
- 表单行：手机号（预填脱敏示例、键盘 phone）；验证码行右侧"获取验证码"文字按钮（default / 倒计时"59s后重发"灰字 / 禁用）；密码行右侧眼睛图标切换明文；输入行 default/focus（蓝色下划线）/error（红字原因，仅失焦或提交校验后展示）。
- 协议勾选行：未勾选时主按钮禁用置灰 `#AEB4BE`，勾选后启用蓝实底；《用户协议》可点击跳协议页。
- 主操作：通栏蓝色按钮 ≥44dp，两屏文案均为"登录"；loading（转圈+禁用）。
- 注册入口：按钮下方居中一行小字"还没有账号？立即注册"，12sp、`#5F6671`、"立即注册"蓝色 `#086CF5` 可点击——视觉层级最低，不与主按钮竞争；另"忘记密码"灰字链接置于密码登录态表单行下方。
- 色彩：主蓝 `#086CF5`；Hero 渐变 `160deg #0872F4→#0B82F8→#1698FA`；页底 `#F6F8FA`；卡片 `#FFFFFF`；error `#FF2D2F`；文字 `#171B23`/`#5F6671`/占位 `#AEB4BE`；分割线 `#E7EAF0`。
- 字体层级：品牌标题 20sp/700；H1 卡片标题 16sp/700；Body 14sp/400；辅助 12sp；脱敏号码 tabular-nums。
- 数据接口（102 已上线）：`POST /auth/sms-code {phone,scene:login}`；`POST /auth/login {phone,mode:sms|password,smsCode|password}`；注册页 `POST /auth/sms-code {scene:register}` + `POST /auth/register {phone,smsCode,password≥10位}`；错误码文案对齐 `Api.friendlyMessage`（40100 凭证无效/40400 账号不存在）。

## 注意事项

- 注册是独立页面，从"立即注册"进入；本稿只约束其入口样式，注册页表单（手机号+验证码+新密码+确认密码）沿用同一卡片骨架。
- 图中手机号示例、Hero 插画为占位，不按图照抄文案比例。
- 频率分层是硬约束：注册入口不得升级为按钮/通栏，防止抢主操作注意力。
- 位图比例不严格：行高 ≥48dp、按钮 ≥44dp、辅助文字 ≥12sp 以本 spec 数值为验收标准。
- 响应式：375-430dp 宽基准；深色模式未设计，token 预留 data-theme 扩展。
- 可访问性：辅助文字对比度 ≥4.5:1；错误状态双线索（颜色+文字）。
