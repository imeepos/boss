## 1. 布局骨架

- 页面结构：顶部蓝色 Hero（约 150dp，含状态栏安全区 + 欢迎区 + 通知按钮 + 装饰弧线）→ 滚动内容区
  （白色卡片纵向排列）→ 固定底部 Tab Bar（4 栏：首页/服务/账单/我的，内容区 48-52dp + 底部安全区）。
- 首卡与 Hero 重叠约 34dp，形成悬浮层级。
- 页面左右边距 16dp；Header 左右边距 24dp；卡片间距 8dp；内容卡宽 = 屏宽 - 32dp。
- 滚动区底部留白 = TabBar 高度 + 安全区 + 8-16dp。

## 4. 圆角与间距

圆角 token：`xs=4dp`（Tag）、`sm=8dp`（按钮）、`md=10dp`（主卡片，统一值）、`lg=12dp`（图标容器/胶囊）、
`pill=999dp`、`full=50%`（头像/红点）。

间距 4dp 网格：`1=4 2=8 3=12 4=16 5=20 6=24 8=32`；页边距 16、卡片间距 8、卡内 padding 16（垂直 12-16）、
图标-文字 8-12、最小点击热区 44x44dp、列表整行热区 ≥56dp。

## 5. 组件形态

- **卡片**：白底 10dp 圆角，无描边或 1dp `#EEF0F3`，柔阴影；层次靠白卡+浅灰背景，不用黑边。
- **Tag**（统一描边浅底样式，高 20-22dp，圆角 4dp，内边距 6-8/2-4）：文字+1dp 描边+极浅底，按语义映射
  success/info/warning/error 四组；**禁止实心高饱和 Tag**。
- **列表行**：`[图标容器40-48dp] 8-12 [标题+副标题 flex] 8 [Tag] 8-12 [箭头18-20dp]`，垂直居中，
  主标题单行省略，Tag 不被压缩。
- **Hero 状态胶囊**：白 16% 透明底、12dp 圆角、12sp 白字、左侧 6-8dp 状态点，段间用 `·`。
- **快捷入口**：88x56dp 热区，图标 24-28dp 在上文字在下（间距 6-8dp），图标按蓝/绿/橙/紫语义分组。
- **操作形态**：文本链接（12sp 蓝 + 箭头）和图标按钮（24dp 图标 44dp 热区）为主，基准页无大面积实心按钮。
- **进度条**：4dp 高、圆头，轨道 `#E7EBF2`、进度 `#086CF5`。

## 6. 图标风格

- 圆角线性图标为主，线宽 1.8-2dp，端点拐角全圆角；导航选中项填充风格。
- 尺寸：入口 24-28dp、卡片业务图标 24-30dp、箭头 18-20dp、导航 24-26dp、状态点 6-8dp。
- 颜色：选中 `#086CF5`、未选 `#666D78`、箭头 `#69717D`、浅底容器 `#F0F6FF`；单图标单色。

## 7. 平台与安全区

- 基准页为 **iOS 视觉语言**（9:41 状态栏、Home Indicator、四栏 Tab Bar）——新设计稿如无特别说明
  沿用 iOS 风格，不再混用 Android 元素。
- 顶部内容起点 = 安全区 + 8-12dp；底部导航背景延伸到屏幕底；ScrollView 底部预留 TabBar+安全区。

## 8. 生图 prompt 用法（ui-proto 预设）

生成新页面时：把第 2-6 节的 token 逐项翻译进 prompt 的 Style/Colors/Components 段，并可用
`--image designs/user-home.png` 作参考图锁风格；生成后 Loop A 按本文件逐项对照。
