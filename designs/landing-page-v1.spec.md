# Sphere Boss 官网首页 实现规格（对应 landing-page-v1.png）

## 给前端的实现提示词（可直接复制）

实现一个 PC 端 SaaS 官网首页（Sphere Boss 电信运营管理平台），高保真还原附图设计稿。

### 整体布局

- **页面骨架**：单列滚动，最大宽度 `max-w-6xl`（1152px）水平居中
- **区块顺序**：sticky 顶栏 → Hero（双栏：左文案 + 右网络图）→ 数据条（深底 3 列）→ 核心功能（6 卡片 3×2）→ 客户成功实践（3 卡片）→ CTA 横幅（深底单栏）→ 页脚（深底版权）
- **页面背景**：`#F4F5F7`（`--shell-content-bg`）

### Hero 区实现要点

- **背景**：使用径向或线性渐变 `linear-gradient(135deg, #E8F0FA 0%, #F4F5F7 70%)` 模拟图中的浅蓝过渡效果；右侧叠加抽象网络图（点阵连线 SVG 或 Canvas 装饰元素，可作背景层）
- **左栏**：标题"Sphere Boss 赋能电信运营"+ 第二行 "全场景管理 · 智能驱动 · 业务增长"（48px/700，深藏青）；副标题段落（14px/400，灰色）；两个 CTA 按钮（主：金底"预约演示"，次：白底描边"了解更多功能"）
- **右栏**：网络抽象图装饰（可作 `position: absolute` 背景层或 SVG inline）；小图占位或纯装饰
- **响应式**：< 768px 时改为单列堆叠，装饰图隐藏

### 顶栏（Sticky）

- **高度**：56px，深藏青底 `bg-[var(--color-brand-navy-950)]`
- **Logo**：圆形金色 logo mark + "Sphere Boss" + 副标题"电信运营管理平台"（白色 18px/700）
- **导航**：3 个链接（产品功能 / 解决方案 / 联系我们），白色 14px/500，hover 金色

## 注意事项

1. **文本地化**：所有中文文案走 i18n（`pages.home.*` 命名空间），同步 `types.ts` + `zh-CN.ts` + `en-US.ts` + `ms-MY.ts` 四处
2. **CTA 文案调整**：设计稿"预约演示"对应原项目内部使用场景，可改为"进入控制台"/"立即登录"（已登录态）/ "预约演示"（未登录对外）—— 已登录态走原版逻辑；未登录态可保留"预约演示"或"立即体验"
3. **Logo**：复用现有 `web/admin/src/assets/brand/logo-mark-gradient.png`，避免重新设计
4. **网络抽象图**：可用 SVG 抽象点阵连线装饰代替图片，实现成本低、可缩放；或使用 `AdCarousel` 类似的多图轮播
5. **响应式**：< 768px 时 Hero 改为单列堆叠、装饰图隐藏、6 卡片变 1 列、3 卡片变 1 列
6. **暗色主题**：本首页建议保持固定亮色主题（品牌对外展示），不跟随系统暗色切换——或实现一个简化版（深底 hero 保留 + 内容区浅色）
7. **客户成功图标**：使用 SVG 描边图标（24 viewBox / stroke 1.8 / round / currentColor），不要用文字字形
8. **可访问性**：CTA 按钮 keyboard 可达、焦点环 `focus-visible:ring-2 focus-visible:ring-ring`；装饰图加 `aria-hidden`
9. **性能**：网络装饰图若用 SVG 内联，应避免过大（< 10KB）；网络图改用静态图片可加 `loading="lazy"` + 响应式 srcset
10. **滚动行为**：锚点链接（产品功能/解决方案/联系我们）平滑滚动到位（`scroll-behavior: smooth`），仅在首页生效、卸载还原
11. **不引用 emoji**：设计稿中"皇冠"图标用 SVG 实现，不用 emoji
12. **设计稿局限**：标题字号/行高由 spec 兜底，位图不保证 dp 级精确；卡片圆角统一 8px 与项目 token 一致
