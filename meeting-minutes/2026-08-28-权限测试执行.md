## 关键结论（先 FAIL 与新发现）

1. **[FAIL·数据层] GET /customers/:id 单资源越权读（D-08）**：ops(rs=root.luzon) 直读达沃客户 id=344 返回 200 完整档案，与"全局不存在 ID"响应可区分。代码根因：customer_handlers.go `customerGetHandler` 不取 DataScope（列表 `customerListHandler` 有 RegionScope 过滤，单资源裸查）。列表裁剪、详情裸查。
2. **[缺陷] PUT /partner/region-scope 完全不可用（V-04）**：partner_admin 对越界区域、企业内公共区域（root.luzon）、甚至清空 scope 一律返回 code=50000 内部错误；GET 复核 regionPath 未被改动（数据未破坏）。根因双重：① regions 表公共区域 legal_entity_id 为 NULL，SQL `legal_entity_id=$2 OR legal_entity_id=0` 匹配不了 NULL → 误判越界；② `partner: region outside enterprise` 等错误未映射业务码。顺带：该接口连"清空区域范围"的合法路径也是坏的。
3. **[缺陷·双证实] 停用账号旧 token 不失效**：代码核验 Authn(JWT 只验签) / HasPermission / GetDataScope 三处均无 status 条件；黑盒印证：号 PUT status=0 后，登录被拒（code=40100）✓，但旧 token GET /auth/me=200、GET /dashboard=200（其权限内接口）——停用不吊销已签发 JWT。verify_e2e 用例原定黑盒（密码未知无法登录），以自建号实证替代，结论：**存疑号 verify_e2e 的存量 token（若在签发有效期内）依然全权可用**。
4. **[暴露面·轻微] GET /install-logs 无 permCode、无数据范围**：technician 可读全部施工回单。同类的 /attachments 列表按登录身份过滤、/search 带 DataScope，无此问题。
5. **[记录] ops 可建产品（V-05）**：POST /products 对 ops 放行，源于迁移 000003 ops 显式绑定 menu:product，按"HasPermission 只查显式行"口径属权限内，非越权；是否应收权移交产品（何平）。
