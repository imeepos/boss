## 2026-09-28 产品资费页编辑/调价/上下架(真实 DOM 断言部署态)
- 部署态 admin-web(102:5180)是 **BrowserRouter**,cdp-capture 用 `/#/bss/product` hash URL 永远落首页/落地页;必须用真实路径 `http://192.168.0.102:5180/bss/product`。
- 部署态 SPA 免登录注入有先后问题:index.html 内联脚本在 boot 时读 localStorage,`--eval setItem` 在页面加载后才执行 → 已触发认证重定向。解法:cdp-capture 带 `--user-data-dir` 持久 profile 分两趟——① 开 `/` 注入 boss.token/servers/active 落库 ② 同 profile 直开目标路由断言 DOM。
- 断言行操作按钮锚点:首行 `table tbody tr[0] button[i]` 按 详情0|编辑1|调价2|上架/下架3|记录4 顺序取;下架确认弹窗文案在 body.innerText 里 grep「确认下架」即可,不必精确 role 定位。
- TS5076:`a ?? (b || c)` 混用 `??` 与 `||` 必须加括号,tsc 直接报错。
- 行内链接按钮规范色令牌是 `var(--color-text-link)`,不是自造 `--color-brand-solid`(幽灵令牌,参见 2026-09-25 审计条)。
