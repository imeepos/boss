用户协议与隐私政策
用户协议

1. 本平台为宽带装维全流程自助服务平台，用户使用前须完成实名认证。

2. 套餐资费以办理时页面展示为准，合约期内退订须按合约约定承担相应责任。

3. 用户应保证所提交地址、联系方式真实有效，用于资源核查与装维上门。

4. 缴费、充值、报障等操作记录与核心系统一致，用户可随时查询。

5. 平台对关键业务（余额/到期/停机/复机/账单/故障）按通知订阅设置推送消息。

隐私政策

1. 收集范围：手机号、实名信息、家庭地址、联系方式，仅用于业务办理与装维服务。

2. 不向第三方出售或泄露用户个人信息，法律法规另有规定除外。

3. 用户可随时在「账号安全」中查看与维护实名信息。

4. 审计日志保留 36 个月，用户关键操作留痕可追溯。
