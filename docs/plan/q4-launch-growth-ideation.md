# 上线放量 · 发散全景与取舍记录

> 配套 `docs/plan/q4-launch-growth-plan.md`。本文记录 2026-09 方向研讨中的全部候选想法及取舍理由，
> 防止"被砍的想法"在下一轮被重新提出时丢失上下文（决策代谢：冻结 + 记录 + 不销毁）。

## 1. 研讨方法

命题：未来 3 个月（2026-09 → 2026-11），战略轴 = 跑通真实业务并增长。
技法组合：四透镜发散（上行/下行/钱账/智能）+ SCAMPER + 反向思考 + 类比移植 + 随机词碰撞。
收敛维度：可行性（依赖门槛）x 影响力（放量贡献）x 新颖度。

### 反向思考的压力测试

- 命题："3 个月做零新功能，只做稳态运营（错误率/超时/对账/客服体验）。" 结论：不可行——供给侧无现场工具、无增长引擎，只守不攻会饿死；但"稳态守夜"作为贯穿辅线采纳（方向一 + 辅线 4.1/4.2）。
- 命题："先放需求侧（营销/官网）还是先放供给侧（工具）？" 结论：供给侧优先——现场工具是装维人力的杠杆，需求拉起来没有工具承接会直接击穿交付承诺；故 M2 排 worker Android，M4 才上活动。

## 3. 收敛结果映射

| 方向 | 吸收候选 | 排序理由 |
|---|---|---|
| 方向一 真实链路稳态 | C1 C2 C3 C4 | 无外部依赖，直接决定"能不能收钱"，放量前提 |
| 方向二 供给侧放量 | B1 B2 B3 | 现场工具是放量杠杆；弱网/离线是真实装维刚性需求 |
| 方向三 增长点火 | A1 A2 A4 A5(+A6 试点) D5 | 底座齐备只缺剧本；渠道是 B 端杠杆，活动是 C 端杠杆 |
| 辅线 守夜 | D1 D2 | 用已有指标目录/对账中心实现，防放量失控 |

## 4. 遣散理由速查（重提前先读这里）

- A3/A7/D6：缺真实销售数据 / 第二区域 / 第二法人，属三年计划第二、三年范畴。
- B4/B5/B6：CS 客服、评价、路径规划都需要真实订单量支撑才有验证条件，放量后再排。
