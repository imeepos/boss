# 投建阶段场景审查报告（只读审查，2026-09-07）

> 审查会话：投建阶段设计审查（负责人派发）。角色：建设/工程负责人视角。全文为审查会话产出原文归档，负责人未改动结论。
> 总评：迁移 000197-000210 把 ODN 从「登记孤岛」推进到「可建单、可结算、可测算」，但以投建全程走查，八段主线中两段走不通（许可路权、资产转固），六段带险；102 生产库 ODN 全链 0 行数据，schema 全在、业务空转。

## 场景逐段结论（八段）

① 投资决策=带险（F1：只有已结算实际成本口径，无规划成本/材料成本/home-passed/区域维度，分光比建模未启动→W5）。
② 规划备案=通过（附 F2：W3 导入只展开箱体设备 odn_device，不产 grid/facility，测算与覆盖两链路数据面断层→W3 收口）。
③ 许可与路权=**走不通/阻塞**（F3：ROW/PECE 只是导入模板列文本；无审批端点；施工单挂不了许可；开工无前置——现实世界会「未获批即开工」；无证照档案实体；无 admin 页面→W4 提级）。
④ 采购供货=带险（F4a：采购与施工零关联，材料出库无单据、材料成本进不了项目→新工作流「项目领料」；F4b：资质自由文本无评级，contractor_type 无 admin 表单列）。
⑤ 施工执行=带险（F5a：BUILDING 期现场零可见性，GIS 实时图层只覆盖 CPE 装机；F5b：勘测采集无人做、师傅端零覆盖、坐标靠桌面录入→W7；F5c：清单无物料维度，开工无任何前置）。
⑥ 竣工验收=通过（附 F6：ACCEPTED 与覆盖 PENDING→SERVED 无联动，门控开闸后「已竣工仍拒单」口径冲突→新裁定，建议随 W4 落）。
⑦ 资产转固=**走不通/阻塞**（F7：asset×odn 零互引；施工建成设施无资产凭证/价值/折旧；材料资产出库后从台账消失；stocktake 只盘库存资产，网络资产不在盘点对象内→新工作流「ODN 资产化转固」）。
⑧ 结算与应付=带险（F8：SETTLED 即终点，无应付台账/付款计划/核减/凭证导出，billing 域零引用结算单→与 W6 预算里程碑合并设计）。
