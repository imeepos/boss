# 师傅端 · 日常处理模拟清单（装维师傅 · 50 轮）

> 目标：以「装维师傅」角色为起点，逐轮模拟师傅**每日真实装维**事件（每轮一个不同事件），
> 每个事件走**完整生命周期**，在师傅端逐一找到对应功能点；凡生命周期中出现而页面/入口未覆盖的触达点，
> 即为需补全的页面/入口。本文档（含 `nav.js` 与 `docs/worker/*.html`）即为补全《师傅端》的推导依据与最终落地。
> 依据：`docs/BOSS综合业务支撑平台/BOSS综合业务支撑平台-需求全案.md` §2.1「装维师傅」职责（领取/接收工单、扫码绑定资产、上报装维结果、异常上报）
> 与 §3.3 业务闭环状态机（新装 12 环节 / 报障服务 6 环节）、`docs/archive/需求提示词-服务端-9阶段拆分.md` 阶段5/6/7/8。
