## 五、使用指引（如何消费交付物）

### 场景 1：业务评审
1. 读《需求全案》第一篇（总览）+ 第二篇（需求）+ 第七篇（落地蓝图）
2. 确认附录 A 待确认参数（38 项，有候选参考）→ 回填后基线冻结 V1.3F
3. 用《00-评估报告》了解适配判定与优化历程

### 场景 2：开发团队实施
1. 读《02-AI自动化开发提示词库》按模块顺序执行（模块 0→6）
2. 每个 Agent 输入包 = 02 库对应提示词 + 需求全案对应章节 + _artifacts 对域交付物
3. 每期开发后按《01-开工检查单》三期启动矩阵推进
4. 验收：T-2 场景清单（200 场景）+ T-1 数据基线 + T-3 联调设计直接可用

### 场景 3：AI 自动化执行（Hermes 环境）
1. 用 delegate_task 按 8.8 输入包机制并行启动 Agent
2. 8.10 多代理协调协议管控跨域（契约+事件）
3. 8.11 迭代回归 + 8.13 评审节点（M1/M2/M4/M6）保持质量闭环
4. 交付物按 8.14 规范归档 _artifacts/

### 场景 4：参数与变更管理
- 参数：附录 A（26 项已回填建议值）+ 38 项待业务确认清单（_artifacts/验收/P1-参数回填映射表.md）
- 变更：任何需求调整走"业务变更建议"流程（8.11），评审后更新基线并升版本
