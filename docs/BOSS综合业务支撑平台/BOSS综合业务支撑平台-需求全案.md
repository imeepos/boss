# 第二篇 需求说明书（正式 SRS）

## 2.1 引言

### 2.1.1 目的

定义菲律宾中大型宽带运营商综合业务支撑平台（服务端）的完整业务需求与验收标准，作为设计、开发、测试、验收与交付的依据。

### 2.1.2 范围

覆盖服务端全部 21 个能力域、6 个业务闭环、数据一致性、非功能需求与合规要求。只描述业务需求与验收标准，不含技术方案。

### 2.1.3 读者

业务决策层、需求评审方、产品经理、开发/测试团队、实施团队、监理与审计方。

### 2.1.4 术语与缩略语

BOSS（综合业务运营支撑系统）、预付/后付（Prepaid/Postpaid）、FUP（公平使用/数据封顶）、pro-rata（首月按日比例）、DPA（数据隐私法 RA 10173）、AMLC（反洗钱委员会）、BIR（国税局）、NTC（国家电信委员会）、ARN（BIR 授权编号）、MoU（批发最低承诺用量）、SLA（服务水平协议）、AR（应收账款）、DSO（应收周转天数）、CLV（客户生命周期价值）。完整三语术语表见附录 C。

# 第四篇 业务架构设计

> 本篇章定义**业务架构**：能力域边界、业务对象模型、域间契约、业务事件、规则落点。技术架构（选型/部署/接口）不属于本篇章，归技术方案阶段（第五篇）。

**拆分原则**：①按能力域拆分（Agent 边界=能力域边界，不跨域）；②按契约协作（只通过 CT-001~010 与业务事件，不直接修改他域数据）；③横切先行（三语/合规/一致性/门户消息一期启动）；④验收独立（每 Agent 独立验收，集成在联调阶段）；⑤阶段匹配（与三期一致）。

**Agent 类型**：能力域 Agent ×18（AG-01~18）；横切 Agent ×4（XG-01~04）；集成验证 Agent ×1。

**启动顺序（三期）**：

```
一期（收款闭环）：XG-01~04 全启动 → AG-01 系统管理（最先）→ AG-14 品牌区域（框架）→ AG-02 CRM → AG-03 计费 → AG-04 支付税务 → AG-05 认证
二期（服务闭环）：AG-06 资源（含资产）→ AG-07 客服 → AG-08 设备监控 → AG-09 应收 → AG-10 渠道
               → AG-15 营收保障 → AG-16 防欺诈 → AG-18 忠诚度（框架）
三期（经营闭环）：AG-11 GIS → AG-12 经营分析 → AG-13 批发 → AG-14 品牌区域（一期启动框架，随期深化）
               → AG-17 结算互连
集成验证 Agent：每期契约联调+闭环验证+当期验收清单
```

## 8.9 验收自动化方案（必读）

> 92 条用例从自然语言转为可自动复现的验收，是"AI 落地"与"人工开发"的关键差异。

| 环节 | 方案 |
|:-----|:-----|
| 用例→测试场景 | 每个 Given/When/Then 用例映射为一个测试场景：Given=初始数据构造，When=业务动作调用，Then=断言 |
| 测试数据生成 | 按 8.9.1 规则生成模拟数据（客户/资产/端口/账单/话单/积分），覆盖正常+边界+异常场景 |
| 断言标准 | Then 中的可测断言：状态/金额/时延/留痕四类，量化阈值取自 REQ 验收标准 |
| 执行框架 | 每期建立"验收基线副本"（附录 A 参数回填后的第二篇+第三篇用例集），用例执行结果记录为"通过/失败+证据" |
| 回归 | 任何变更后重跑本域用例 + 受影响契约联调用例（见 8.11） |

**8.9.1 测试数据生成规则**：
- 客户：模拟 [1,000] 户（个人/企业/集团/预付/后付分布），覆盖标签/等级/风险状态；
- 资源：模拟 [10] 个分光器 × [64] 端口 = [640] 端口，覆盖空闲/预占/在用/故障；
- 账务：模拟余额/账单/话单/积分流水，覆盖临界（余额=阈值、账单=税额边界）；
- 边界数据：到期前 [3] 天、停机 [7/30/90] 天、超量 [100]%、大额 ≥₱[500,000] 等；
- 数据一致性：生成后先通过 CONS 核对用例，保证测试基线自身一致。

## 8.10 多代理协调协议（必读）

> 并行子代理无法直接通信；域间协作统一走"契约+事件"，联调由集成验证 Agent 集中执行。

| 机制 | 规则 |
|:-----|:-----|
| 契约即接口 | Agent 间数据交互仅通过 CT-001~012；任何跨域数据读写必须经契约定义，禁止直接改他域数据 |
| 契约测试 | 每个契约由集成验证 Agent 编写联调场景（引用 7.3 联调表），在集成环境执行，通过才视为域间可用 |
| 模拟桩 | 下游 Agent 未就绪时，上游 Agent 使用模拟桩（按契约切片返回预设数据），联调后换真实实现 |
| 冲突仲裁 | 契约争议按第四篇冲突处理原则（以主权域为准）；无法裁决时升级需求方（8.13 评审节点） |

## 8.11 迭代与回归机制

| 规则 | 说明 |
|:-----|:-----|
| 验收基线冻结 | 附录 A 参数确认后，第二篇 REQ + 第三篇用例集冻结为 V1.2 基线；业务变更须提"变更建议"经评审后更新基线并升版本 |
| 变更影响分析 | 变更建议必须声明影响的 REQ/用例/契约/Agent；评审后按影响范围触发回归 |
