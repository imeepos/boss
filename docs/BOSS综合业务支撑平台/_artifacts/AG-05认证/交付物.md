## 1. 业务对象清单

### 1.1 会话（Session）

**用途**：客户从认证成功到连接结束的在线实例，是本域实时计费记录（时长/流量）与话单生成的最小执行单元；同时供客服实时查询与 RA 稽核消费。

| 属性 | 说明 |
|:-----|:-----|
| sessionId | 会话标识（全局唯一；每次成功认证生成新会话，重连不续接旧会话，AAA-003） |
| subscriptionId / accountId / customerId | 归属订购关系 / 账户 / 客户（N:1） |
| authMethod | 认证方式：PPPoE / DHCP / Hotspot / 静态IP / LOID（取自认证配置，AAA-001） |
| accessRef | 接入标识：宽带账号 / LOID / 静态 IP / 线路端口（随认证方式不同而不同） |
| authProfileId | 采用的认证配置标识（含凭证核验结果） |
| authorizeParams | 授权参数快照：套餐带宽（上下行速率上限）、QoS 优先级/模板（AAA-002 授权结果，随会话记录，供计费/RA 稽核） |
| regionId / brandId | 所属区域 / 品牌（AAA-005 维度，话单与策略解析共用） |
| startTime / endTime | 会话起 / 止时间（业务时间） |
| duration | 时长（秒，会话结束时最终固化） |
| trafficUp / trafficDown | 上 / 下行流量累计（在线期间周期性快照累计，实时记录） |
| endReason | 结束原因：正常下线 / 强制下线（停机/欠费/管理）/ 超时 / 异常中断（设备重启等） |
| graceExemptFlag | 宽容窗口豁免标记：强制下线 5 分钟窗口内产生的用量是否豁免计费（供计费侧执行"期间用量不追讨"） |
| status | 会话状态（见状态集） |

**状态集**：

| 状态 | 含义 | 触发/解除 |
|:-----|:-----|:-----|
| AUTHENTICATING 认证中 | 认证请求已受理，正在核验（凭证+服务状态） | 请求受理；核验通过/拒绝后离开 |
| ACTIVE 在线 | 认证通过、授权已生效，实时记录时长/流量 | 认证通过；正常/强制下线/超时后离开 |
| DISCONNECTING 下线中 | 强制下线指令已执行，等待下线确认 | 强制下线触发；确认后置结束态 |
| TERMINATED 已结束 | 会话结束，话单已生成 | 结束确认；话单生成后归档 |

**关系**：Session N:1 Subscription；Session 1:1 话单（每会话结束生成一张话单）；会话授权参数引用套餐带宽/QoS 模板（授权模板对象）。

### 1.2 话单（CDR）

**用途**：会话结束生成的计费依据记录，交付计费域（AG-03）计费、RA（AG-15）稽核；是"会话数据供计费/RA 消费"的载体。

| 属性 | 说明 |
|:-----|:-----|
| cdrId | 话单号（全局唯一，幂等键：同一会话只允许一张话单，重连生成新会话新话单） |
| sessionId | 来源会话标识（1:1） |
| subscriptionId / accountId / customerId | 归属订购关系 / 账户 / 客户 |
| authMethod / accessRef | 认证方式 / 接入标识（与会话一致） |
| startTime / endTime / duration | 会话起止与时长 |
| trafficUp / trafficDown | 上 / 下行流量 |
| authorizeParams | 授权参数快照（带宽/QoS，供计费校验与 RA 稽核） |
| regionId / brandId | 区域 / 品牌（计费与 RA 按此分域消费） |
| endReason | 结束原因（正常/强制下线/超时/异常） |
| graceExemptFlag / graceWindow | 宽容豁免标记及窗口（强制下线 5 分钟内用量不追讨的标识） |
| status | 话单状态（见状态集） |

**状态集**：

| 状态 | 含义 |
|:-----|:-----|
| GENERATED 已生成 | 会话结束生成话单，待交付计费 |
| DELIVERED 已入计费 | 已交付计费域（≤[X] 分钟，见 CHG-AAA-002），计费域已接收 |
| DELIVERY_FAILED 交付失败 | 交付失败待重试（重试幂等：话单号唯一，不重复入账） |
| RECONCILED 已稽核 | 已被 RA 稽核对账（差异闭环后置） |

### 1.3 服务状态（订阅认证侧视图）

**用途**：认证侧维护的"订阅是否可服务"判定依据。**本域不判定余额/欠费**，仅消费计费域经 CT-006 下发的停机/复机状态并镜像；认证判定（放行/拒绝/强制下线）以本视图为准。为满足认证响应 <500ms，判定数据在认证侧即时可读（镜像机制见第 5 节），一致性以计费侧为准，定期对账。

| 属性 | 说明 |
|:-----|:-----|
| subscriptionId | 订购关系标识（与计费侧一致） |
| serviceStatus | 服务状态（见状态集，镜像计费侧 Subscription 状态，保持子类细分便于拒绝原因区分） |
| lastEventSeq | 最近一次状态事件的序号（幂等键，与计费侧事件序号一致，重复事件跳过） |
| lastEventTime | 最近一次状态变更时间 |
| effectTime | 状态生效时间（停机/复机即时生效；强制下线宽容窗口自该时间起算 5 分钟） |
| source | 状态来源（计费域事件 / 批量处置任务） |

**状态集**（镜像计费侧口径，见 AG-03 交付物 1.2）：

| 状态 | 认证侧处置 |
|:-----|:-----|
| ACTIVE 可服务 | 允许认证与继续服务 |
| SUSPENDED_BALANCE 余额停机 / SUSPENDED_AR 欠费停机 / SUSPENDED_ADMIN 管理停机 / EXPIRED 过期 | 拒绝新认证；在线会话触发强制下线（5 分钟宽容窗口） |
| REACTIVATING 复机中 | 复机指令已接收未完成回执，仍拒绝新认证 |
| CANCELLED 终止 | 拒绝认证，配置失效 |

**关系**：ServiceStatus 1:1 Subscription（计费侧主权，认证侧镜像）；1:N Session（在线会话受状态约束）。

### 1.4 认证配置（AuthProfile）

**用途**：订阅当前生效的认证方式与接入凭证组合，是"认证方式与套餐绑定（AAA-001）"的执行载体；变更需重新下发配置。

| 属性 | 说明 |
|:-----|:-----|
| authProfileId | 认证配置标识 |
| subscriptionId | 归属订购关系（1:1 生效配置；变更生成新版本） |
| planId | 绑定套餐标识（认证方式随套餐确定） |
| authMethod | 认证方式：PPPoE / DHCP / Hotspot / 静态IP / LOID（一次仅启用一种） |
| credential | 凭证信息：宽带账号/密码、LOID 注册标识、门户账号、静态 IP 绑定（IP+线路）、DHCP 可选 MAC 绑定 |
| bandwidthTemplateId / qosTemplateId | 授权模板引用：套餐带宽模板 / QoS 模板（按区域+品牌解析，AAA-005） |
| regionId / brandId | 所属区域 / 品牌（策略与模板解析维度） |
| version / status | 配置版本与状态（见状态集） |
| deployTime / invalidTime | 下发生效时间 / 失效时间（变更后旧版本失效） |

**状态集**：

| 状态 | 含义 | 触发 |
|:-----|:-----|:-----|
| PENDING_DEPLOY 待下发 | 新装/变更后配置已生成未下发 | 订购/套餐变更 |
| DEPLOYING 下发中 | 正在下发至认证执行点 | 下发动作启动 |
| EFFECTIVE 生效中 | 已下发成功，用于认证判定 | 下发成功 |
| INVALID 失效 | 被新版本替换/订阅终止 | 新配置生效/终止 |

**关系**：AuthProfile 1:1 Subscription（有效版本）；N:1 套餐（认证方式来源）；N:1 授权模板（区域+品牌解析）。

### 1.5 授权模板（带宽/QoS 模板）

**用途**：套餐带宽（上下行速率）与 QoS（优先级/队列策略）的标准化定义，按"区域+品牌"独立维护（AAA-005），认证通过时随会话下发授权（AAA-002）。

| 属性 | 说明 |
|:-----|:-----|
| templateId | 模板标识 |
| templateType | 类型：带宽模板 / QoS 模板 |
| regionId / brandId | 适用区域 / 品牌（区域间独立，互不影响） |
| bandwidthUp / bandwidthDown | 上下行速率上限（带宽模板） |
| qosLevel | QoS 等级/优先级（QoS 模板） |
| status | 状态：ENABLED 启用 / DISABLED 停用（停用对新会话生效，存量会话保持，口径见 CHG-AAA-004） |

### 1.6 批量处置任务（BatchTask）

**用途**：按区域/品牌/名单批量停机/复机的任务化载体（AAA-004），任务可配置执行时间，结果可统计留痕（AAA-TC3）。

| 属性 | 说明 |
|:-----|:-----|
| batchTaskId | 任务标识 |
| action | 动作：批量停机 / 批量复机 |
| filter | 目标筛选：区域 / 品牌 / 名单（可组合，执行时快照锁定目标集合） |
| planTime | 计划执行时间（可配置：立即执行或定时执行，支持错峰，见第 5 节） |
| throttle | 节流参数：每批数量、批间隔（防与认证高峰挤压） |
| status | 任务状态（见状态集） |
| execSummary | 结果统计：总数 / 成功 / 失败 / 跳过（已是目标状态）/ 失败原因分布 |
| auditRef | 留痕：创建人/时间、审批、执行过程明细 |

**状态集**：

| 状态 | 含义 |
|:-----|:-----|
| PENDING 待执行 | 已创建未到计划时间 |
| RUNNING 执行中 | 分批处置进行中 |
| COMPLETED 已完成 | 全部处理完（可含失败项，失败项支持重跑） |
| FAILED 失败中止 | 批量级失败中止，可重跑 |

**关系**：BatchTask 1:N 处置明细（每订阅一条：成功/失败/跳过+原因）；处置指令复用单条停机/复机机制与 CT-006 幂等键。

## 2. 规则实现说明（AAA-001~005，含例外）

### AAA-001 认证方式与套餐绑定（PPPoE/DHCP/Hotspot/静态IP/LOID）；变更需重新下发配置

**实现逻辑**：
1. **方式与套餐绑定**：认证方式定义在套餐（产品域）上；订阅订购/变更套餐时，按套餐生成该订阅的认证配置（含凭证、接入参数、授权模板引用），一次仅启用一种认证方式。
2. **混合管理**：五种认证方式各自独立配置与验收（PPPoE=宽带账号/密码；DHCP=可选 MAC 绑定；Hotspot=门户账号/密码；静态IP=IP 与线路绑定；LOID=注册标识），同区域/品牌下可并存不同方式的客户，互不影响（REQ-AAA-001 验收"各方式可分别配置验收"）。
3. **配置下发**：认证配置须"下发"后方可生效（新装/变更走下发流程）；**变更需重新下发**：新版本生成（PENDING_DEPLOY）→ 下发成功置 EFFECTIVE → 旧版本置 INVALID。下发失败自动重试，重试期间**旧配置继续生效**（不因变更导致存量客户断网），超限升级人工（见遗留事项）。
4. **服务状态联动**：订阅停机/复机不影响认证配置本身，仅影响认证判定（服务状态对象），复机后无需重新下发配置即可恢复认证（复机即时生效，CT-006）。

**例外（欠费停机瞬间在线）**：欠费/停机判定瞬间仍有在线会话的，发起**强制下线**，宽容窗口 **[5] 分钟**内生效；窗口内会话继续产生的用量**不追讨**——实现上会话话单保留并打"宽容豁免"标记（含窗口起止），由计费侧豁免该时段费用、RA 可稽核（口径见 CHG-AAA-005）。

### AAA-002 认证通过按套餐带宽/QoS 授权；停机/欠费/过期拒绝或强制下线

**实现逻辑**：
1. **认证判定**：凭证核验（按认证方式） + 服务状态核验（仅 ACTIVE 放行） + 认证配置有效性核验，三者通过才认证成功。
2. **授权**：认证通过后按套餐对应的带宽/QoS 模板授权（上下行速率上限、QoS 优先级），授权参数随会话记录（供计费校验与 RA 稽核）。
3. **停机/欠费/过期处置**：服务状态非 ACTIVE（余额停机/欠费停机/管理停机/过期）→ **拒绝新认证**（返回拒绝原因区分停机/欠费/过期/凭证错误）；**在线会话** → 经 CT-006 状态事件触发**强制下线**（5 分钟宽容窗口，AAA-001 例外同口径）。

**例外（认证高峰超时自动重试）**：认证高峰认证请求超时时，客户端自动重试；重试以幂等键（订阅+接入标识+会话标识）去重——**同一认证请求重试不重复建会话、不重复计费**，重试成功仅创建一次会话、生成一张话单。

### AAA-003 会话实时记录；会话结束生成话单入计费；重连生成新会话

**实现逻辑**：
1. **会话实时记录**：认证成功即创建会话（新会话标识）；会话存续期间**实时记录时长与上下行流量**（周期性快照累计，快照周期可配置），供客服实时查询与 RA 稽核。
2. **话单生成**：会话结束（正常下线/强制下线/超时/异常中断）即生成话单（含起止时间、时长、流量、结束原因、授权参数、豁免标记），话单 **≤[X] 分钟入计费**（建议值见 CHG-AAA-002），话单号唯一保证不重复入账。
3. **重连生成新会话**：每次成功认证=新会话（新会话标识），重连**不续接**旧会话；旧会话未正常结束的按**超时判定**结束（无流量/无心跳超时阈值，见遗留事项）并照常生成话单，**不丢单**（保证会话数据完整率）。
4. **消费方**：话单交付计费域（AG-03 计费）与 RA（AG-15 稽核），本域只生产不消费。

**例外（设备重启大量重连）**：设备重启导致大量重连（重连风暴）时，重连请求**排队处理**（排队策略见第 5 节），**已认证会话优先保持**（在线会话不被挤占、不主动断开）。

### AAA-004 批量处置：按区域/品牌/名单批量停机复机，任务可配置执行时间

**实现逻辑**：
1. **任务建模**：批量处置任务按"区域/品牌/名单"（可组合）筛选目标订阅集合；动作=批量停机/批量复机；**执行时间可配置**（立即或定时，支持错峰）。
2. **执行**：到计划时间后，逐订阅生成处置指令（复用单条停机/复机机制与 CT-006 幂等键：订阅标识+事件序号），**节流分批**下发（防与认证高峰挤压）；每订阅结果留痕（成功/失败/跳过+原因）。
3. **统计与留痕**：任务完成输出汇总（总数/成功/失败/跳过/原因分布），明细可查询；失败项支持重跑（幂等：已处置项跳过）——满足 AAA-TC3"全部成功明细可统计留痕"。
4. **批量处置对在线会话**：批量停机对在线会话同样触发强制下线（5 分钟宽容窗口同 AAA-001 例外口径）。

**例外**：规则表无例外项；批量任务与认证高峰并发的规避策略见第 5 节（错峰+节流+分流）。

### AAA-005 认证策略与带宽模板按区域/品牌独立

**实现逻辑**：
1. **独立配置**：认证策略（允许的认证方式集合、认证参数、超时/重试/排队规则）与带宽/QoS 模板按"**区域+品牌**"维度独立维护。
2. **解析规则**：订阅按其所属区域/品牌解析认证策略与授权模板（认证配置引用该解析结果）；一个区域/品牌的策略或模板变更**只影响该区域**（验收"区域间互不影响"）。
3. **模板变更生效口径**：模板停用/调整对新会话生效，存量在线会话按会话内授权参数保持（不中途变更，避免在线客户体验突变）；如需立即生效走批量处置（与 CHG-AAA-004 同口径，待确认）。

**例外**：规则表无例外项。

## 3. 用例通过记录（验证设计，未运行）

> 说明：本域无真实运行环境，以下为**验证设计**（Given/When/Then + 预期证据），用于指导 T-2 用例自动化执行阶段；执行结果待回填，未虚构运行结论。

### AAA-TC1 停机拒认证（停机客户设备在线尝试认证→拒绝；复机后 [X] 分钟恢复）

**验证场景设计**：
- **Given**：订阅 A 服务状态 ACTIVE、认证配置生效（PPPoE）；计费域经 CT-006 下发停机事件（事件序号 N，原因=欠费），认证侧服务状态镜像更新为 SUSPENDED_AR、生效时间 T0；订阅 A 设备在线（会话 S1 ACTIVE）。
- **When**：
  - 停机生效后，设备发起新认证请求（凭证正确）；
  - 同时，在线会话 S1 触发强制下线流程。
- **Then**：
  - 新认证**被拒绝**（拒绝原因=欠费停机），不创建新会话；
  - 在线会话 S1 在 **[5] 分钟**宽容窗口内完成强制下线（结束原因=强制下线，话单带宽容豁免标记）；
  - 计费侧下发复机事件后（[X] 分钟，建议即时，见 CHG-AAA-003），设备重新认证**成功**、新会话创建并正常授权。

**预期证据**：认证拒绝记录（时间戳、订阅、认证方式、拒绝原因）；无新会话创建记录；强制下线执行记录（时间戳 ≤ T0+5min）与 S1 话单（豁免标记、结束原因=强制下线）；复机事件接收记录（事件序号 N+1）；复机后认证成功与会话创建记录。

**边界注记**：用例"复机后 [X] 分钟恢复"为占位符，与 CT-006"停机/复机即时生效"（已评审采纳，见 CHG-BIL-004）存在口径差 → 变更建议 CHG-AAA-003（统一即时生效）。

### AAA-TC2 并发认证（D 档并发压力测试→响应/成功率达标报告为附件）

**验证场景设计**：
- **Given**：D 档规模压测环境，构造并发认证请求 30-50 万（覆盖五种认证方式，含停机客户请求与重复/重试请求）；
- **When**：按规模档位并发执行认证压力测试，记录响应时延与成功率；
- **Then**：认证响应 <500ms、成功率达标（阈值占位待回填，见 CHG-AAA-002）；停机/欠费客户**全部被拒绝**（无一获得服务）；重试/重复请求**不产生重复会话与重复话单**（会话数=唯一认证成功数，话单数=会话数）。

**预期证据**：压力测试报告（附件，含并发量、响应时延分布、成功率、错误分布）；停机客户拒绝记录抽样核对（拒绝率 100%）；会话创建数=话单数 的幂等校验结果（差异 0）。

**边界注记**：REQ-AAA-002 验收占位符（响应 ≤[X]ms、并发 ≥[X] 万）未回填 → 变更建议 CHG-AAA-001。

### AAA-TC3 区域批量停机（区域批量停机任务→全部成功明细可统计留痕）

**验证场景设计**：
- **Given**：区域 R1 批量停机任务（筛选=区域 R1，动作=停机，计划执行时间已到），R1 内订阅 10,000 条（含 200 条已停机订阅、50 条在线会话订阅）；
- **When**：任务执行（分批节流下发处置指令）；
- **Then**：R1 内全部订阅停机成功（含 200 条"跳过"=已是目标状态）；在线会话订阅触发强制下线（5 分钟宽容窗口）；任务输出汇总统计（总数/成功/失败/跳过）与逐订阅明细，全程留痕可查。

**预期证据**：任务记录（筛选条件、计划/实际执行时间、节流参数、结果统计）；处置明细 10,000 条（成功 9,800 / 跳过 200 / 失败 0，各带时间戳与原因）；在线会话强制下线回执 50 条；任务留痕（创建人、执行过程、重跑记录）。

**边界注记**：失败项重跑机制（幂等跳过已处置项）在设计中覆盖，具体重跑阈值（自动重试次数/人工介入）待压测与运维流程确定（见遗留事项）。

## 4. 契约联调要点（CT-006 余额-服务状态：计费 → 认证）

### CT-006 停机/复机即时生效、强制下线（宽容规则）

| 要点 | 内容 |
|:-----|:-----|
| 本域角色 | **接收方/消费者**：消费计费域"服务已停机/复机"状态事件（4.5 事件），更新服务状态镜像并执行（拒绝新认证/强制下线）；**本域不判定余额/欠费** |
| 时延达成 | **停机/复机即时生效**（CT-006 已冻结）：停机事件接收→状态镜像更新→新认证立即拒绝、在线会话强制下线（宽容窗口 **5 分钟**，窗口内用量不追讨）；复机事件接收→状态更新→认证立即恢复（建议 ≤5 分钟，见 CHG-AAA-003） |
| 强制下线（宽容规则） | 停机瞬间在线会话不立即掐断：**[5] 分钟**内完成强制下线；窗口内用量话单保留并标记"宽容豁免"，计费侧豁免该时段费用、RA 可稽核（口径见 CHG-AAA-005）；已豁免用量**不追讨**（与 AAA-001 例外一致） |
| 幂等要求 | 指令携带"订阅标识 + 事件序号"（与 AG-03 计费侧一致）：重复事件跳过；目标状态=当前状态跳过（判等幂等）；**状态一致性以计费侧为准**，认证侧定期对账修复差异（对账频率建议日级，见遗留事项） |
| 失败处理 | 事件接收失败→重试（上限 3 次）→超限列入未闭环清单跟踪；批量任务失败批次支持重跑（幂等跳过已处置项）；强制下线无回执的会话列入异常清单 |
| 联调验证点 | ①停机→新认证拒绝、在线会话 5 分钟内强制下线且期间用量豁免（话单标记）；②复机→认证即时恢复；③重复停机/复机事件幂等（无重复动作）；④批量停机/复机（区域/品牌/名单）与认证 30-50 万并发能力匹配（节流分批）；⑤设备重启重连风暴期间已认证会话优先保持 |

## 5. 并发认证性能设计要点（D 档：认证响应 <500ms、并发 30-50 万）

> 目标基线：认证响应 **<500ms**、并发 **30-50 万**（D 档全国旗舰）。本节仅描述**业务层面的并发策略**（判定数据、排队、复用、降级、幂等），不涉及技术选型与部署架构。

| 策略 | 业务设计 |
|:-----|:---------|
| **判定数据本地化（镜像）** | 认证判定所需数据（服务状态、认证配置、授权模板）在认证侧**即时可读**，认证请求**不实时回源计费域**——保证 500ms 内完成判定；镜像由 CT-006 事件驱动更新，辅以定期对账（与第 4 节一致） |
| **通道复用（连接池业务口径）** | 认证处理通道按"区域+品牌"**分片池化复用**（AAA-005 天然分片）：同分片内请求共享通道，避免每请求重建开销；**批量处置指令走独立通道**，与认证请求分流，互不挤占 |
| **排队与优先级** | 认证请求排队处理；优先级：**已认证会话的重连/续连 > 新认证**（AAA-003 例外"已认证会话优先保持"）；队列饱和时对新认证返回"繁忙请重试"（客户端退避重试），不无限排队 |
| **重连风暴处理** | 设备重启大量重连：排队 + 节流 + 退避建议；在线会话不被挤占、不主动断开；重连请求幂等去重（AAA-003 例外） |
| **幂等去重** | 认证幂等键（订阅+接入标识+会话标识）：重试/重复请求**不重复建会话**；话单号唯一：**不重复计费**（AAA-002 例外"自动重试不重复计费"落地） |
| **会话记录与话单解耦** | 会话实时记录（时长/流量快照）轻量写入，不阻塞认证路径；话单在会话结束时生成、**批量交付计费（≤[X] 分钟）**，与认证请求解耦（AAA-003） |
| **降级策略** | ①局部故障→仅受影响"区域+品牌"分片降级，其他分片不受影响（区域间互不影响）；②认证能力不足→**已认证会话优先保持**（不主动断开），新认证拒绝/排队——业务上宁可拒绝新认证，**不可放行停机客户**（REQ-AAA-002"停机/欠费不可获得服务"为硬约束）；③话单本地暂存、恢复后补传（会话数据完整率达标，见 CHG-AAA-002）；④批量处置降级为延后分批执行（错峰） |
| **批量任务错峰** | 批量停机/复机任务默认**错峰执行**（可配置执行时间+节流参数），禁止在认证高峰无限并发，与 30-50 万认证能力匹配（AAA-TC3/CT-006 联调验证） |
| **验收证据** | AAA-TC2 压力测试报告（附件）：并发 30-50 万下响应 <500ms、成功率达标、停机客户拒绝率 100%、会话/话单幂等差异 0 |
