## 1. 业务对象清单

> 对照 4.2：User/Role/AuditLog（系统管理）与 BusinessParameter（系统管理）为本域对象；Permission 在 4.2 中并入 User/Role 概念，本设计显式化（功能权限点 + 数据权限规则）。1.6 辅助对象为支撑 SYS-004/005/006 的设计补充，不改变 4.2 对象定义。

### 1.1 User（用户账号）

| 项 | 说明 |
|:---|:-----|
| 业务定义 | 可登录系统的用户主体（内部员工、经销商、批发客户、自助客户） |
| 关键属性 | 用户ID、登录名（员工工号 / 手机号）、姓名（三语）、所属组织（部门 + 区域节点 + 品牌）、绑定角色集合（可多角色）、状态、密码设置时间（90 天更换计时起点）、连续失败次数、锁定截止时间、最后登录时间、语言偏好、生效/失效日期 |
| 状态集 | **正常 / 已锁定 / 已停用 / 已注销**（状态流转必须合规：正常⇄已锁定（失败锁定或人工锁定）、正常⇄已停用（管理员操作，留痕）、已注销不可逆；非法流转被拒并提示，对齐 GEN-011/012） |
| 归属域 | 系统管理（AG-01）主权 |

### 1.2 Role（角色）

| 项 | 说明 |
|:---|:-----|
| 业务定义 | 功能权限与数据权限的授权载体，15 类业务角色 + 1 个审计角色（见 1.7） |
| 关键属性 | 角色ID、角色编码、角色名称（三语）、角色类型（业务角色/审计角色/系统内置角色）、授权功能权限集合、授权数据权限规则集合、适用范围（品牌/区域限制）、状态 |
| 状态集 | **启用 / 停用**（停用即时生效：停用角色的所有用户立即失去相应权限） |
| 归属域 | 系统管理（AG-01）主权；角色授权操作属敏感操作（二次确认+审批，GEN-009） |

### 1.3 Permission（权限：功能权限 + 数据权限）

| 项 | 说明 |
|:---|:-----|
| 业务定义 | 功能权限：可执行的功能操作点；数据权限：可访问的数据范围（品牌/区域/部门三维） |
| 功能权限属性 | 权限点ID、权限点编码、所属能力域与功能模块（如"计费-出账执行""CRM-客户档案-修改"）、操作类型（查看/新增/修改/删除/审批/导出）、三语名称、状态 |
| 数据权限属性 | 规则ID、维度（品牌 / 区域 / 部门）、授权范围（品牌集合、区域节点**含全部下级节点**、部门集合）、继承规则（按层继承，对齐 REQ-REG-004）、状态 |
| 状态集 | **启用 / 停用**（权限点或规则停用即时生效） |
| 归属域 | 系统管理（AG-01）主权；品牌/区域/部门维度主数据由品牌区域域（AG-14）维护，本域读取用于联动（REQ-SYS-005），不自行维护维度树 |

### 1.4 AuditLog（审计日志）

| 项 | 说明 |
|:---|:-----|
| 业务定义 | 关键操作全程留痕、不可篡改、可检索、保留 36 个月（REQ-SYS-003；覆盖 GEN-008 清单：登录/权限变更/订单/账单调整/收款退款/资产资源配置变更/调价/额度/批量任务，以及本域全部管理操作） |
| 关键属性 | 日志ID、操作时间（Asia/Manila，GEN-004）、操作人（用户ID/姓名/角色）、操作类型、业务对象与对象ID、操作内容摘要（变更前后值）、结果（成功/失败/被拒）、来源渠道（WEB/App/自助门户/第三方）、终端标识、关联单据号、品牌/区域维度、防篡改校验值、归档标记 |
| 状态集 | **在线可检索 / 已归档（归档后仍可检索）/ 已过保留期（36 个月后走销毁流程，审批+留痕）**；在线期与归档期内容均不可修改、不可删除（运维窗口例外，例外动作本身留痕） |
| 归属域 | 系统管理（AG-01）主权；各域上报关键操作事件，本域统一留存 |

| 项 | 说明 |
|:---|:-----|

| 关键属性 | 参数ID、参数编码、参数名（三语）、当前值、历史值（版本保留）、生效范围（全局/品牌/区域/渠道/单据类型）、生效时间、状态、修改留痕（修改人/时间/原因/审批人） |
| 参数域示例（初始化清单，P0-2） | 计费（余额提醒阈值 ₱50、欠费停机阈值 30 天、有效期规则）、SLA（工单时限/升级阈值）、通知（模板/频控）、税率（VAT 12% 等）、汇率（业务发生日配置汇率，GEN-005）、密码策略（强度/90 天/锁定阈值，SYS-001）、会话超时（30 分钟，SYS-002）、审计归档阈值（BCR-AG01-04） |

| 11 | 经销商 | 经销商门户（开户/充值/佣金查询） | 本品牌 + 本经销商所辖区域与客户 | 佣金欺诈检测联动（FMS） |

| 13 | 总部经营分析 | 全域报表/经营分析（只读） | **全品牌 + 全国（总部全量，只读）** | 汇总=各区域之和（REQ-REG-001）；报表口径合规（REQ-COMP-006/007） |

**权限三维模型**：功能权限（操作点）× 数据权限（品牌 + 区域 + 部门三维，区域按层继承）× 用户主体（账号绑定角色集合）；任一维度判定不通过即拒绝并审计（越权被拒）。权限变更保存即生效，已登录会话实时重算，不等下次登录。

## 2. 规则实现说明（SYS-001~005，条件→动作→结果）

### 2.1 SYS-001 密码与账户安全（支撑 REQ-SYS-001/005）

**规则原文**：密码 ≥10 位含大小写+数字；90 天更换；失败 5 次锁定 30 分钟。例外：锁定期自助找回（短信验证码重置并强制更换）。

**业务实现逻辑**：

| 条件 | 动作 | 结果 |
|:-----|:-----|:-----|
| 新用户设置/用户修改密码 | 校验密码强度（≥10 位，含大写、小写、数字各至少 1 位） | 不满足→拒绝并提示原因；满足→保存，记录密码设置时间（90 天计时起点）；修改密码操作记入审计（GEN-008） |
| 密码使用满 90 天 | 下次登录强制进入更换流程，更换前不可使用业务功能 | 未更换无法进入系统；更换成功留痕；不可回退使用旧密码 |
| 登录连续失败累计达 5 次（第 5 次失败） | 立即锁定账号 30 分钟（锁定截止时间=第 5 次失败时间+30 分钟）；生成锁定审计记录 | 账号状态=已锁定；锁定期内任何尝试（含正确密码）均被拒绝并产生"锁定拒绝"审计记录（对齐 SYS-TC1"第 6 次尝试→锁定+审计"断言） |
| 锁定期内（例外）自助找回 | 短信验证码验证（依赖 XG-04 消息通道）→ 重置密码并强制下次登录更换 | 解锁成功；审计记录"自助重置"；原密码立即失效；短信通道未就绪时由系统管理员人工解锁（留痕，见遗留 R-03） |
| 锁定 30 分钟到期 | 自动解除锁定 | 恢复可登录；首次正确登录成功记录 |
| 权限变更（角色/功能权限/数据权限调整、账号停用） | 保存即生效；已登录会话权限实时重算 | 下一次操作即按新权限判定；越权操作被拒并审计（"越权被拒"记录，供举证） |

**数据权限联动（REQ-SYS-005）**：数据权限按"品牌 + 区域 + 部门"三维判定；区域权限按组织树层级继承（区域运营经理=本区域含全部下级节点；总部经营分析=全量）。品牌维度强制隔离（跨品牌访问 0，REQ-BRAND-001）。组织树结构变化（AG-14 维护）即时反映到权限判定。

### 2.2 SYS-002 会话与敏感操作（支撑 REQ-SYS-001/002）

**规则原文**：会话超时 30 分钟自动登出；敏感操作二次确认。例外：审计日志存满：归档后仍可检索，归档留痕。

**业务实现逻辑**：

| 条件 | 动作 | 结果 |
|:-----|:-----|:-----|
| 用户空闲（无任何操作）达 30 分钟 | 会话失效，自动登出 | 后续操作要求重新登录；未提交的编辑内容不落库，提示"会话已过期，请重新登录"（防数据丢失） |
| 执行敏感操作（退款/调价/信用单/坏账核销/权限授予/参数修改/第三方接入审批等，对齐 GEN-009 清单） | 二次确认（确认弹窗 + 再次验证身份凭证） | 确认后执行，记录审批人；无审批权限者操作进入待审批队列（GEN-009 例外）；全程留痕 |
| 审计日志存储接近容量上限（例外） | 触发归档（归档阈值/周期为可配置参数，BCR-AG01-04） | 归档后仍可检索；归档动作本身记入审计（归档留痕） |

### 2.3 SYS-003 审计日志（支撑 REQ-SYS-003）

**规则原文**：审计保留 36 个月；内容不可修改删除（运维窗口除外留痕）。

**业务实现逻辑**：

| 条件 | 动作 | 结果 |
|:-----|:-----|:-----|

## 3. 用例通过记录（验证设计）

> **重要声明**：无真实运行环境，以下均为**验证场景设计 + 预期证据判定准则**（如何验证），执行状态=待执行；实际通过/失败结果由 T-2（用例自动化执行）/T-3（契约联调）阶段按本设计执行后回填。不得将本设计视为已运行通过。

### 3.1 SYS-TC1 密码锁定（支撑 SYS-001）

**验证场景 SYS-TC1-S01**：

- **Given**：账号 A 处于正常状态、无失败记录；已配置 SYS-001 密码策略；测试数据含账号 A 已知正确密码；系统时间可控制（支持时间推进模拟 30 分钟）。
- **When**：连续输入错误密码 5 次（第 1~5 次均失败），随后第 6 次尝试输入**正确**密码。
- **Then**：
  1. 第 5 次失败后账号 A 状态=已锁定，锁定截止时间=第 5 次失败时间+30 分钟；
  2. 第 6 次尝试被拒绝（即使密码正确），提示"账号已锁定，请于 30 分钟后重试或通过短信验证码自助找回"；
  3. 审计日志产生：登录失败记录 5 条（含每次时间/来源）+ 账号锁定记录 1 条（操作人=系统）；
  4. 模拟推进 30 分钟后首次正确登录成功，锁定解除；解锁事件留痕。
- **预期证据**：审计查询结果（账号 A，类型=登录失败×5 + 账号锁定 + 锁定拒绝 + 解锁）；账号状态快照（锁定时间戳）；第 6 次尝试拒绝回执；30 分钟后登录成功记录。
- **判定准则**：锁定时间戳=第 5 次失败时间+30min；第 6 次尝试被拒；审计记录齐全（含失败/锁定/拒绝/解锁四类）；30 分钟内任何尝试均被拒。
- **状态**：验证设计（待执行）。

### 3.2 SYS-TC2 备份与恢复演练（支撑 SYS-004）

**验证场景 SYS-TC2-S01（备份执行）**：

- **Given**：备份计划已配置（每日全量 + 每 6 小时增量 + 变更数据实时归档）；模拟数据基线（客户/账单/参数，对齐 8.9.1 测试数据）。
- **When**：按计划触发全量备份与增量备份；模拟业务数据变更后触发变更归档。
- **Then**：BackupRecord 记录完整（类型/时间/范围/校验值/结果=成功）；人为制造备份失败场景→产生告警与重试记录（GEN-010 失败条目单独重试，不整批重跑）。
- **预期证据**：备份任务执行记录（含校验值）、失败重试与告警记录。
- **判定准则**：备份成功记录完整；失败场景告警+重试闭环存在。

**验证场景 SYS-TC2-S02（恢复演练）**：

- **Given**：最近一次全量+增量+变更归档可用；演练环境就绪（D 档数据规模）；故障点时间 T 已定义。
- **When**：执行恢复演练（恢复至演练环境，模拟故障点 T），核对恢复数据与 T 时刻前业务数据的一致性并计时。
- **Then**：恢复后数据与 T-5min 内业务数据一致（RPO 验收口径）；恢复完成时延 ≤2h（RTO）；DrillRecord 结论=通过；另设演练不一致场景→标记未通过、复盘整改、整改后复演直至通过（SYS-004 例外），整改闭环留痕。
- **预期证据**：恢复演练报告（恢复数据量/一致性核对结果/恢复时延）；DrillRecord 状态=通过；不一致场景的整改记录。
- **判定准则**：RPO/RTO 达标；3 个月周期内存在"通过"演练记录；不通过场景有整改闭环。
- **状态**：验证设计（待执行；恢复计时由集成验证 Agent 执行）。

### 3.3 SYS-TC3 第三方接入（支撑 SYS-005）

**验证场景 SYS-TC3-S01**：

- **Given**：第三方（支付渠道）申请接入已登记，状态=申请中；审批人与申请人账号可用；支付域以模拟桩提供（8.10 协议）。
- **When**：提交接入审批→审批通过→接入配置生效→进入运行；模拟第三方故障（断连/超时）；随后恢复；再发起断开审批并执行断开。
- **Then**：
  1. 状态流转完整：申请中→已审批→接入中→运行中→已断开，每步有时间戳与操作人；
  2. 接入全流程可审计（申请/审批/配置变更/状态切换/断开均有审计记录）；
  3. 模拟故障→产生故障告警（关联接入登记）并触发降级预案（转人工代收/现金代收），降级执行有记录；
  4. 恢复后复测通过，故障处理闭环留痕。
- **预期证据**：ThirdPartyAccess 状态流转记录；审计时间线（接入相关操作）；故障告警记录与降级处理记录；断开审批记录。
- **判定准则**：审批前后状态正确；全程审计无缺失；故障告警在预期阈值内产生；降级预案执行有记录。
- **状态**：验证设计（待执行；依赖支付域模拟桩与 XG-04 消息通道）。

## 4. 契约联调要点（本域作为被依赖方）

> 依据 8.10 多代理协调协议：域间协作统一走"契约+事件"，本域不在 CT-001~012 业务契约编号内（业务契约属各业务域之间数据流转），本域提供的是**横切服务能力**，被全部域依赖（4.1 系统管理：被全部域依赖）。

### 4.1 向其他域提供的能力与调用条件

| 能力 | 提供内容 | 消费方 | 调用条件 | 失败处理 |
|:-----|:---------|:-------|:---------|:---------|
| 权限服务（功能+数据） | 操作前功能权限判定、查询/操作数据权限过滤（品牌/区域/部门三维，按层继承）、权限变更即时生效、越权被拒留痕 | 全部域（AG-02~18、XG） | 每次业务操作前调用；判定实时（满足核心响应 <500ms）；权限/组织变更保存即生效，会话实时重算 | 权限服务故障默认拒绝（越权保护优先，fail-closed），业务操作暂停并告警；**不得默认放行** |
| 审计服务 | 关键操作审计事件统一留痕（GEN-008 清单）、防篡改、36 个月保留、检索/导出、合规举证 | 全部域（各域上报事件）；合规（XG-02）举证消费 | 关键操作发生/失败/被拒时上报（含操作人/对象/结果/品牌区域/单据号）；上报不阻断业务 | 上报失败进入待补传队列，恢复后补传并留痕；审计服务故障不阻断业务 |

| 备份恢复服务 | 全系统备份统一调度（每日全量+增量+变更归档）、恢复预案与演练组织 | 全部域（数据纳入备份范围） | 备份范围含各域数据；恢复演练后由各域验证自身数据完整性 | 备份失败告警+重试，连续失败升级；演练未通过标记未通过，复盘整改直至通过 |
| 第三方接入管理 | 外部系统统一登记/审批/审计/故障告警/降级 | 支付域（渠道接入）、消息域（短信/Messenger）、GIS（地图）、BI 等 | 第三方接入须先经本域审批登记；故障降级预案按接入类型配置 | 第三方故障→告警+降级预案执行，业务不中断 |
| 组织-权限联动 | 多组织结构（区域/品牌/部门）变化即时联动数据权限（REQ-SYS-005） | 品牌区域域（AG-14）提供维度主数据 → 本域联动 | 组织树新增/调整/停用后数据权限即时重算 | 联动失败告警并阻止权限误放行 |

### 4.2 关键前置依赖（本域需要其他方提供）

1. 品牌区域域（AG-14）：品牌/区域/部门组织树维度主数据（本域只读消费，不自行维护）；
2. 消息通知（XG-04）：短信验证码通道（SYS-001 密码自助找回）；未就绪期间锁定账号由系统管理员人工解锁（留痕）；
3. 三语（XG-01）：本域界面文案、角色名/参数名/权限点名三语；
4. 合规（XG-02）：审计日志消费方（举证），本域提供检索与导出能力。

### 4.3 联调方式（8.10 协议）

- 各域 Agent 通过"契约即接口"方式调用本域能力；本域未就绪时，下游域使用模拟桩（按能力定义返回预设判定结果），联调后换真实实现；
- 契约争议按主权域原则裁决（本域对 User/Role/Permission/AuditLog/BusinessParameter 及备份/接入数据主权；组织树主权在 AG-14）；
- 事件驱动：本域能力调用不依赖业务事件顺序；各域对权限/参数消费须幂等（重复调用不产生重复结果）；
- 联调执行由集成验证 Agent 按 7.3 流程集中执行，本域交付"能力定义 + 验证场景设计"（第 3 章）供联调消费。
