## 1. 业务对象清单

### 1.1 RA Reconcile Record（稽核差异单，4.2 主对象）

**用途**：营收保障全部稽核产出的**统一差异载体**（4.2 定义：稽核单号、类型、差异金额、状态），承载话单缺失/重复、批价差异、收入差异、异常复核五类稽核结果；是 CT-011"稽核单、差异明细"的推送单元与差异处理闭环的跟踪单元。

| 属性 | 说明 |
|:-----|:-----|
| reconcileId | 稽核单号（全局唯一；CT-011 推送与回执的幂等键） |
| auditType | 稽核类型：CDR_MISSING 话单缺失 / CDR_DUPLICATE 话单重复 / RATING_DIFF 批价差异 / REVENUE_DIFF 收入差异 / EXCEPTION_REVIEW 异常复核 |
| auditBatchId | 来源稽核批次号（见 1.2） |
| diffAmount | 差异金额（收入/批价类必填；缺失/重复/复核类可为 0 或关联金额） |
| diffDirection | 差异方向：多计 / 少计 / 漏计 / 重复 / 待核验 |
| sourceRef | 关联业务单据：话单号 / 账单号 / 支付单号 / 订单号 / 信用单号 / 退款单号（跨域引用，仅存标识不存明细） |
| assigneeDomain | 处置责任域：计费（AG-03）/ 支付（AG-04）/ 订单（AG-02）/ 稽核岗（本域复核） |
| dueTime / escalateFlag | 处理时限（RA-002/003 时限、RA-004 复核时限）/ 超时升级标记 |
| handler / handleOpinion / closeTime | 处理人 / 处理意见 / 闭环时间（留痕） |
| status | 状态（见状态集，4.2 冻结） |

**状态集**（4.2 冻结）：待处理 / 处理中 / 已闭环。

| 状态 | 含义 | 触发/解除 |
|:-----|:-----|:-----|
| PENDING 待处理 | 稽核生成、待责任域/稽核岗认领处理 | 稽核运行生成；认领后置处理中 |
| PROCESSING 处理中 | 已认领、正在处置（补单/冲账/更正/复核核验） | 认领；处置完成并回执后置已闭环 |
| CLOSED 已闭环 | 处置完成、回执确认、留痕完整 | 处置回执校验通过（差异清零或核验为正常） |

**关系**：Reconcile Record 1:N 差异明细（1.3，下钻数据）；N:1 稽核批次（1.2）；经 sourceRef 关联各域单据（只读引用）；稽核报表（1.5）按单聚合统计。**本对象不持有各域数据副本，差异明细仅存比对所需的标识与比对快照**（如话单号、原/新金额、规则版本号）。

### 1.2 稽核批次（AuditBatch）

**用途**：日稽核任务的运行载体与留痕，保证"日稽核"可调度、可重跑、可统计（对应 CT-011"日稽核"）。

| 属性 | 说明 |
|:-----|:-----|
| auditBatchId | 批次号（全局唯一；"稽核类型+稽核日+范围分片"为幂等键，重复运行不重复生成稽核单） |
| auditType | 稽核类型（五类之一） |
| auditDate | 稽核业务日（T 日；日稽核 T+1 运行） |
| scope | 稽核范围：区域/品牌分片、抽样比例（批价稽核）或全量（话单/收入比对） |
| runStatus | 未开始/处理中/已完成/失败（断点续跑依据） |
| resultStats | 结果统计：比对总数、差异数、差异金额、重处理数、闭环数 |
| ruleVersion | 本次稽核采用的规则/资费版本快照（批价重算依据） |
| runTime / operator | 运行时间 / 运行方式（自动调度/人工重跑） |

**关系**：AuditBatch 1:N Reconcile Record；失败批次支持重跑（幂等，已生成稽核单跳过）。

### 1.3 差异明细（ReconcileDetail，下钻数据）

**用途**：稽核单的可下钻明细行（满足 REQ-RA-002/003"可下钻到明细"、REQ-RA-005"数据可下钻"），按稽核类型承载比对结果快照。

| 属性 | 说明 |
|:-----|:-----|
| detailId / reconcileId | 明细标识 / 归属稽核单号 |
| sourceRef | 明细级关联单据：话单号（cdrId）/ 账单号 / 支付单号 / 渠道交易号（channelTxnId）/ 订单号 |
| compareSnapshot | 比对快照：原值 vs 稽核值（话单：认证侧 vs 计费侧；批价：原批价 vs 重算价；收入：计费/收款/实收三方金额） |
| diffAmount / diffReason | 明细差异金额 / 差异归因初判（缺失、重复、规则版本差异、资费配置差异、时点差异、渠道差错、其他） |
| handleResult | 处置结果回填：已补单 / 已冲账 / 已更正 / 核验正常 / 转案件（FMS） |

### 1.4 异常复核任务（ExceptionReviewTask）

**用途**：RA-004 四类异常（低价套餐 / 异常折扣 / 大额信用单 / 异常退款）自动进复核队列的任务载体，挂接 Reconcile Record（auditType=EXCEPTION_REVIEW）。

| 属性 | 说明 |
|:-----|:-----|
| reviewTaskId | 复核任务标识（与稽核单 1:1 关联） |
| triggerType | 触发类型：LOW_PRICE_PLAN 低价套餐 / ABNORMAL_DISCOUNT 异常折扣 / LARGE_CREDIT_NOTE 大额信用单 / ABNORMAL_REFUND 异常退款 |
| hitRule | 命中规则及阈值（配置化，见 RA-004） |
| riskLevel | 风险等级：低/中/高（按金额与类型组合初判） |
| relatedRef | 关联单据：订单号 / 信用单号 / 退款单号 / 支付单号 |
| reviewStatus | 待复核 / 复核中 / 已复核 / 超时升级 |
| reviewer / conclusion / reviewTime | 复核人 / 结论（正常放行 / 异常处置：拒绝、撤销、调整、转风控）/ 复核时间（留痕） |

**关系**：ExceptionReviewTask 1:1 Reconcile Record（同单双视图）；N:1 订单（AG-02）；信用单/退款单经 AG-03/AG-04 只读引用。

### 1.5 稽核报表（AuditReport）

**用途**：REQ-RA-005 日/周/月稽核报表的元数据（报表生成、推送、下钻入口），报表内容由稽核批次与稽核单统计得出。

| 属性 | 说明 |
|:-----|:-----|
| reportId | 报表标识（"类型+期间"幂等） |
| reportType | 日报 / 周报 / 月报 |
| period | 报表期间（日报=T 日；周报=自然周；月报=自然月） |
| indicators | 指标集：稽核覆盖率、重算差异率、差异金额合计、闭环率、超时升级数、复核队列积压（口径见第 2 节） |
| drillPath | 下钻路径：报表 → 稽核批次 → 稽核单 → 差异明细 |
| pushTarget / pushTime | 推送对象（财务、稽核岗）/ 推送时间（日报 T+1 09:00 前） |
| status | 生成中 / 已推送 / 推送失败待重推 |

## 2. 规则实现说明（RA-001~004 含例外，及 REQ-RA-005 补充）

> 执行顺序按任务基线：**1 话单稽核 → 2 批价稽核 → 3 收入差异 → 4 异常复核 → 5 稽核报表**。前四项为规则实现，第五项为需求补充实现。所有稽核**只读消费**他域数据、差异处置回写由主权域执行（CT-011），本域不直接改账。

### RA-001 话单稽核（完整率核查；重复/缺失自动检出进重处理；重处理不改变原始话单、留痕）

**实现逻辑**：
1. **数据源与比对基准**：认证域（AG-05）会话话单（每会话 1:1，cdrId 唯一）为"应稽核全集"；计费域（AG-03）已消费话单（话单状态达 DELIVERED/已入账）为"已接收集合"。以 **cdrId 为幂等键**做集合比对（两侧只读）。
2. **完整率核查**：完整率 = 已接收话单数 ÷ 应稽核话单数（按稽核日归属，口径见遗留事项）；完整率 < 100% 即启动差异检出（验收基线"稽核覆盖率 ≥95%"为稽核覆盖口径，见 CHG-RA-001）。
3. **缺失检出**：认证侧有话单、计费侧未接收（或长期滞留 DELIVERY_FAILED）→ 生成缺失话单清单（会话号、结束时间、缺失原因分类：交付失败/漏交付/交付中），落稽核单（auditType=CDR_MISSING）+ 明细。
4. **重复检出**：同 cdrId 出现多条话单、或同会话产生多话单、或计费侧重复入账迹象 → 生成重复话单清单（auditType=CDR_DUPLICATE），作为对 CT-005 幂等防重的二次核查（重复入账理论上被渠道交易号/流水号唯一性拦截，RA 做独立复核）。
5. **重处理**：缺失话单经稽核岗确认后**重新交付计费域**（复用话单交付机制，幂等：话单号唯一，不重复入账）；重复话单由计费侧按冲账/红冲路径处置（BIL-005）。
6. **留痕（规则例外原文）**：重处理**不改变原始话单**——认证侧 CDR 只读，重处理生成独立的"重处理记录"（批次、时间、操作人、话单号、结果），话单状态在重处理闭环后置 RECONCILED（AG-05 口径"已被 RA 稽核对账"），原始内容零改动。

**例外与边界处理**：
- **宽容豁免话单**（强制下线 5 分钟窗口内豁免标记）：仍参与完整性稽核（话单必须存在），但豁免标记不因稽核而改变；计费侧按豁免口径不追讨，RA 不将其列为批价/收入差异。
- **话单交付时限依赖**：缺失判定依赖 AG-05"话单交付 ≤[X] 分钟"（REQ-AAA-003 占位符未回填，P1 参数清单）→ 在交付时限内的话单不判缺失（容忍交付窗口），超时未交付才进缺失清单（见 CHG-RA-006）。
- **重处理幂等**：同话单重复重处理不重复入账（以 cdrId 判重）；重处理失败自动重试（上限 3 次），仍失败列入重处理失败清单人工介入。

### RA-002 批价稽核（按计费规则重算，不符自动标记复核；差异处理闭环时限 [X] 天）

**实现逻辑**：
1. **稽核范围**：抽样或全量（300 万级话单/用量建议抽样+差异放大复核，比例配置化；口径见 CHG-RA-001）。
2. **重算基准**：取**话单发生时点生效的计费规则版本快照**（资费/价目/折扣/VAT 12%/批发 MoU 等，与 AG-03 同一规则体系），重算批价金额——**必须用历史版本，防止资费变更后误报**。
3. **比对与标记**：原批价金额 vs 重算金额 → 差异 ≠ 0 且超差异阈值（小额差异忽略阈值配置化）→ **自动标记复核**：生成稽核单（auditType=RATING_DIFF）与明细（原/新金额、差异金额、规则版本号、差异原因初判）。
4. **复核处置**：复核岗核验差异归因（规则版本差异 / 资费配置错误 / 计费缺陷 / 取数口径差异）→ 处置：计费缺陷与资费配置错误由计费侧按**冲账/信用单路径**调整（关账后账期受 BIL-005 约束，禁止直接改流水）→ 处置回执后稽核单闭环，全程留痕（复核人、意见、时间、调整单据号）。
5. **差异率指标**：重算差异率 = 差异话单数 ÷ 稽核话单数（或差异金额 ÷ 稽核金额，口径待确认，见 CHG-RA-002），验收基线 ≤0.5%；差异率超阈值触发质量告警（属系统质量指标，不拦截业务，见 RA-TC3 注记）。

**例外与边界处理**：
- **差异处理闭环，处理时限 [X] 天**（占位符，建议 3 天，见 CHG-RA-002）：稽核单带 dueTime，超时自动升级（升级通知稽核岗负责人）。
- **规则版本一致性**：重算必须绑定话单发生时点版本；版本缺失（资费无历史版本记录）→ 该批话单标记"待补版本"不臆造差异（遗留事项，依赖计费域规则版本化）。
- **关账约束**：已关账账期的批价差异只允许冲账/信用单路径（BIL-005），RA 只标记与跟踪，不直接改账。

### RA-003 收入差异分析（计费收入 vs 收款 vs 实收三方对比，可下钻；日差异报表自动生成；差异处理闭环时限 [X] 天）

**实现逻辑**：
1. **三方口径定义**（口径需财务确认，见 CHG-RA-003）：
   - **计费收入**：计费域（AG-03）当期产生的收入——后付出账单金额 + 预付扣费流水（按账期/按日汇总，与"收款/实收"的时点口径差异需归因分类）；
   - **收款**：支付域（AG-04）支付单（收款到账，按 receivedTime/paidTime 汇总）；
   - **实收**：渠道实收确认——银行转账对账批次、电子钱包渠道对账单等（按渠道对账确认日汇总；银行转账按批次到账，PAY-001 例外，存在自然时滞）。
2. **两两对比**：①计费收入 vs 收款（应收 vs 实收资金：应收未收/多收错收，即 RA-TC2 场景）；②收款 vs 实收（系统收款 vs 渠道实收：渠道差错、未达账）；③计费收入 vs 实收（间接校验）。差异归因初判：时点差异（账期/到账日/确认日错位，滚动核对后自动消解）vs 真实差异（漏收、多收、错收、渠道差错）。
3. **可下钻**：四级下钻——总额 → 账期/渠道 → 账户 → 明细单据（账单号/支付单号/渠道交易号/账务流水），满足"差异可下钻到明细"。
4. **差异处理闭环**：真实差异生成稽核单（auditType=REVENUE_DIFF），按责任域指派（计费侧补单/冲账；支付侧渠道差错更正/追回），处置回执闭环；时限 [X] 天（建议 3 天，CHG-RA-003）。
5. **日差异报表自动生成**：每日稽核运行完成后自动生成日差异报表（T+1），推送财务（详见 REQ-RA-005 补充实现）。

**例外与边界处理**：
- **差异处理时限 [X] 天**（占位符，同 RA-002 建议 3 天）：超时升级。
- **口径时滞容忍**：银行转账按对账批次入账（PAY-001）、渠道对账 T+N → 实收确认滞后于收款，稽核以"归因分类 + 滚动核对"处理，不将时点差异当作真实差异误报；时点差异在下一稽核周期自动消解后置"已闭环（核验正常）"。
- **充值与账单收入分列**：预付充值（非账单收入）与后付出账（账单收入）分口径统计，避免混同（口径待财务确认）。

### RA-004 异常订单复核（低价套餐 / 异常折扣 / 大额信用单 / 异常退款自动进复核队列；复核时限 [X] 天，超时升级）

**实现逻辑**：
1. **触发源与特征规则（阈值配置化并冻结，见 CHG-RA-004）**，命中即自动生成复核任务（auditType=EXCEPTION_REVIEW + ExceptionReviewTask）：
   - **低价套餐**：订单/订购套餐价格显著低于产品目录价或同类历史成交价（如低于目录价 [X]%，建议默认 50%，配置化）；
   - **异常折扣**：折扣率超阈值（如 >[X]%，建议默认 30%）、促销叠加超出规则（AG-02 促销叠加规则外）、无审批折扣（折扣审批缺失）；
   - **大额信用单**：信用单金额 ≥ 阈值（建议与 PAY-004 大额审批联动口径，≥₱10,000 起复核，高等级按更大金额分档）；
   - **异常退款**：退款金额/频次/退款率异常、原路退款失败转人工（PAY-004 例外）、退款与支付单金额不符。
2. **自动进复核队列**：命中即生成复核任务（关联订单/信用单/退款单，初判风险等级），进入待复核队列；复核清单自动生成（REQ-RA-004 验收）。
3. **复核处置**：复核岗核验 → 结论：正常放行 / 异常处置（拒绝、撤销、调整）→ 处置动作由所属域执行（订单域撤销订单、支付域拦截退款等），RA 跟踪处置回执；涉及欺诈嫌疑的升级转防欺诈域（AG-16 FMS）案件调查（边界：RA 只做复核队列与处置跟踪，欺诈案件调查归 FMS）。
4. **超时升级**：复核时限 [X] 天（建议 2 天，见 CHG-RA-004），超时自动升级（升级通知上级稽核岗/合规岗，升级记录留痕，escalateFlag 置位）。

**例外与边界处理**：
- **复核时限 [X] 天，超时升级**（规则例外原文）。
- **与既有审批联动**：大额退款已有 PAY-004 两级审批、大额现金已有 AMLC 标记（PAY-005）——RA 复核与既有审批**并行不替代**：审批管"能否执行"，RA 复核管"是否异常"，两套留痕独立。
- **阈值配置变更**走参数变更留痕（XG 参数管理），变更不回溯历史复核结论。

### 补充实现说明（REQ-RA-005 稽核报表：日/周/月自动生成推送，数据可下钻）

**实现逻辑**：
1. **报表类型与期间**：日报（T 日，T+1 生成）、周报（自然周，次周一）、月报（自然月，次月 1 日，与出账/关账节奏衔接）。
2. **指标口径**：稽核覆盖率（稽核话单数 ÷ 应稽核话单数，≥95%）、重算差异率（≤0.5%）、收入差异金额与闭环率、批价差异处理闭环率、复核队列积压与超时升级数、重处理成功率。
3. **自动生成与推送**：报表按调度自动生成（幂等：类型+期间唯一），自动推送财务与稽核岗（日报 T+1 09:00 前）；推送失败自动重推（上限 3 次）。
4. **可下钻**：报表 → 稽核批次 → 稽核单 → 差异明细 逐级下钻（1.5 drillPath），支撑差异定位与举证（GOAL-8 合规可举证）。

## 3. 用例通过记录（验证设计，未运行）

> 说明：本域无真实运行环境，以下为**验证设计**（Given/When/Then + 预期证据），用于指导 T-2 用例自动化执行阶段；执行结果待回填，未虚构运行结论。

### RA-TC1 话单缺失检出（计费话单缺 100 条 → 缺失清单生成进重处理，重处理闭环）

**验证场景设计**：
- **Given**：认证域（AG-05）当日生成话单 100,000 条；计费域（AG-03）已接收 99,900 条（缺失 100 条，均为话单交付失败/超时未交付）；稽核覆盖率阈值 95%；日稽核任务于 T+1 运行。
- **When**：日稽核任务对当日话单执行完整率核查（以 cdrId 比对两侧）。
- **Then**：
  - 检出缺失 100 条，生成缺失话单清单（话单号、会话号、结束时间、缺失原因）；
  - 生成稽核单（类型=话单缺失）+ 100 条明细，进入重处理流程；
  - 重处理执行：100 条重新交付计费域并成功入账（幂等：无重复入账），话单置 RECONCILED；
  - 重处理留痕完整，原始话单内容未被修改。
- **预期证据**：缺失清单 100 条（含缺失原因分类）；稽核单与明细（100 条）；重处理记录（批次号、时间、操作人、100 条成功）；重处理后话单状态=RECONCILED；原始话单一致性校验（重处理前后逐字段比对无变化）；完整率 = 99,900/100,000 = 99.9% > 95% 达标。

**边界注记**：用例"缺 100 条"未定义缺失判定窗口（交付时限内的话单是否判缺失）→ 依赖 AG-05 话单交付时限占位符回填（CHG-RA-006）；"稽核覆盖率 ≥95%"为稽核覆盖口径而非完整率口径，全案占位符 [X]% 待回填（CHG-RA-001）。

### RA-TC2 收入差异（计费 ₱100 万 vs 收款 ₱99.5 万 → 差异 ₱0.5 万可下钻明细，处理闭环）

**验证场景设计**：
- **Given**：当日计费收入（出账+扣费口径）₱1,000,000；支付域收款（支付单到账口径）₱995,000。
- **When**：日收入差异分析运行（计费收入 vs 收款对比）。
- **Then**：
  - 差异 **₱5,000**（= ₱0.5 万）生成稽核单（类型=收入差异，方向=应收未收，责任域=计费/应收）；
  - 差异可下钻：总额 → 账期/渠道 → 账户 → 明细单据（账单号/支付单号/渠道交易号）；
  - 责任域处置（补单/催收/冲账）后回执，稽核单闭环留痕。
- **预期证据**：稽核单（差异金额 ₱5,000、方向、责任域、时限）；下钻明细（逐级可查至账单/支付单）；处置记录与闭环时间戳；日差异报表（含该差异行）。

**边界注记**：用例未区分"时点差异 vs 真实差异"——若差异源于账期/到账日错位，按 RA-003 归因分类处理（滚动核对消解），不误报；三方口径（计费收入构成、实收定义）待财务确认（CHG-RA-003）。

### RA-TC3 批价复核（100 话单批价与规则不符 → 标记复核，差异处理留痕）

**验证场景设计**：
- **Given**：稽核范围内话单 10,000 条；其中 100 条批价与计费规则重算结果不符（原批价 ≠ 重算价，超差异阈值）。
- **When**：批价稽核按规则重算运行（重算绑定话单发生时点规则版本）。
- **Then**：
  - 100 条全部**自动标记复核**（稽核单类型=批价差异 + 明细：原/新金额、差异金额、规则版本号）；
  - 复核处置（归因核验 → 冲账/信用单调整或核验正常）后闭环，**差异处理全程留痕**（复核人、意见、调整单据、时间）。
- **预期证据**：批价差异稽核单 1 张 + 明细 100 条（各带原/新金额与差异）；复核处置记录 100 条（结论、调整单据号、时间戳）；闭环稽核单；差异率 = 100/10,000 = 1.0%。

**边界注记**：用例中差异率 1.0% **超过**验收基线 0.5%——差异率 ≤0.5% 是系统质量指标（超阈值告警复盘），**不是拦截条件**（用例仍要求"标记复核、处理留痕"），两者不冲突；差异率口径（按话单数 vs 按金额）待确认（CHG-RA-002）；用例 100 条全部标记复核与"小额差异忽略阈值"的边界（若部分差异低于忽略阈值则不标记）需在阈值配置化时统一（CHG-RA-004）。
