## 1. 业务对象清单

> 说明：4.2 对象模型仅列 Wholesale Contract/Usage 一行（状态集 履行中/结算中/已结算/争议），且该状态集语义偏向账单结算周期而非合同/用量本身（见 CHG-WHO-004）。本节为**本域细化建模**（4.2 相关延伸），供需求评审补充 4.2 时引用。金额精度统一按 GEN-006。

### 1.1 批发客户档案（Wholesale Customer Profile）

**用途**：批发客户主数据承载（REQ-WHO-001"档案"）。批发客户建档复用 CRM 客户主数据（4.3 以 CRM 为准），本域维护批发专属属性，支撑合同、门户、对账的客户维度。

| 属性 | 说明 |
|:-----|:-----|
| customerId | 客户标识（CRM 主数据，本域引用） |
| customerName / tin | 企业名称 / TIN（BIR 税务标识，发票开具依据） |
| brand / region | 品牌 / 区域维度（批发品牌，全局横切维度） |
| siteList | 批发站点/线路清单（每条线路关联合同与资源端口） |
| slaContact | SLA 联系人（故障受理联系人，用于 SLA 通知） |
| portalAccount | 门户账号引用（1.8，站点级数据隔离） |
| status | 状态沿用 CRM 客户状态（潜在/已签约/在网/暂停/已流失），本域以"在网"为可出账前提 |

**关系**：批发客户档案 1:N 批发合同；1:N 批发账单；1:N 门户账号；N:1 CRM Customer（主数据以 CRM 为准，冲突告警按 4.3）。

### 1.2 批发合同（Wholesale Contract）

**用途**：批发业务核心对象（WHO-001 / REQ-WHO-001），承载合同五要素（客户/产品/价目/MoU/SLA/账期）与变更审批，是计费、结算、毛利分析的共同依据。

| 属性 | 说明 |
|:-----|:-----|
| contractId | 合同号（系统生成唯一，GEN-001） |
| customerId / productId | 客户 / 产品（批发带宽线路） |
| priceVersion | 价目快照版本（签约时价目版本为准，后续调价不影响存量合同，与 AG-09 账期方案快照口径一致） |
| mou | MoU 最低承诺用量（如 100Mbps，WHO-003 保底计费依据） |
| sla | SLA 要素（带宽可用率、故障响应时限，与客服域工单 SLA 衔接） |
| paymentTerms | 账期（付款账期，与应收域 AG-09 账期方案衔接） |
| effectiveDate / expireDate | 生效日 / 到期日（到期提醒消费"合同即将到期"事件，4.5） |
| changeApprovals | 变更审批链记录（价目/MoU/SLA/账期变更均需审批留痕，REQ-WHO-001 验收） |
| version | 合同版本（变更生成新版本，历史版本保留不可改） |

**状态集**：基线 4.2 为 履行中/结算中/已结算/争议——其中"结算中/已结算/争议"实为账单结算周期状态，应挂结算单/账单（见 CHG-WHO-004）；本域建模：合同生命周期状态（草稿/已签署/履行中/到期/终止，沿用 4.2 Quote/Contract 通用状态）**+** 当期结算周期状态（履行中/结算中/已结算/争议，4.2 基线保留，作为合同维度结算跟踪标记）。

**关系**：批发合同 1:N 批发用量；1:N 批发账单；1:N 结算单；N:1 批发价目（快照）；变更审批 N:1 审批记录（留痕）。

### 1.3 批发价目与阶梯费率（Wholesale Price List）

**用途**：批发定价载体（REQ-PROD-006 批发定价 / WHO-003），承载合同价、MoU 费、超量单价与阶梯档位，按月重置规则配置。

| 属性 | 说明 |
|:-----|:-----|
| priceListId | 价目标识 |
| contractId | 关联合同（合同价目以签约时版本快照为准） |
| mouFee | MoU 合同价（如 ₱50,000/月） |
| excessUnitPrice | 超量单价（如 ₱1,000/计费单位；单位折算口径见 CHG-WHO-002） |
| tierRules | 阶梯档位配置（多档超量单价，按月重置，不跨月累计） |
| effectiveDate / expireDate | 生效期（调价审批后生效，生效日不得早于审批通过日） |
| version / approver | 版本 / 最近审批人（调价审批留痕，REQ-PROD-006 与 WHO-001 变更审批） |

**关系**：价目 1:N 批发合同（快照引用）；调价影响预览（受影响合同与收入变化预估，对齐 REQ-PROD-005 调价预览口径）。

### 1.4 批发用量（Wholesale Usage）

**用途**：用量采集结果载体（WHO-002 / CT-010 产生数据），计费与对账的共同数据源。

| 属性 | 说明 |
|:-----|:-----|
| usageId | 用量记录标识 |
| contractId / circuitId | 合同 / 线路（幂等键组成部分：合同+周期+线路） |
| billPeriod | 归属周期（YYYYMM，按合同周期，月度） |
| usageValue | 用量值（峰值带宽/流量/端口占用，3.3.5"采集峰值/流量/端口"） |
| collectTime / completeness | 采集时间 / 完整率（周期完整率 ≥99%，REQ-CL-005/WHO-002） |
| missingFlag | 缺失标记"待补"（CT-010 失败处理；缺失记录不参与当期出账，补采后重算） |
| billedFlag | 入账标记（已入计费后不可变） |

**状态集**：已采集 / 待补（缺失标记）/ 已补采 / 已入账。原始采集记录不可变，补采留痕（对齐 RA-001"重处理不改变原始话单"口径）。

**关系**：批发用量 N:1 批发合同；1:N 补采记录；采集完成后发布事件"批发用量已采集"（4.5，消费方：计费出账、结算对账）。

### 1.5 批发账单（Wholesale Bill）

**用途**：批发计费出账载体（WHO-003 / WHO-004），MoU 保底、超量计费、VAT 拆分的结果单据，结算与争议处理的起点。

| 属性 | 说明 |
|:-----|:-----|
| billNo | 账单号（系统生成唯一，GEN-001；幂等键=合同+周期，不重复出账） |
| contractId / customerId | 合同 / 客户 |
| billPeriod | 账期（YYYYMM，周期结束出账） |
| mouAmount / excessAmount | MoU 费 / 超额费（WHO-003 计算） |
| vatAmount / totalAmount | VAT 税额 / 含税总额（VAT 口径见 CHG-WHO-003；税款单独计算，GEN-006） |
| priceVersion / usageSnapshot | 价目快照 / 用量快照（计费依据留痕） |
| errorRateFlag | 差错率验收标记（REQ-WHO-002 / WHO-TC1B 对账差错率 ≤[X]%） |

**状态集**：待客户确认 / 结算中 / 已结算 / 争议 / 已作废（WHO-004 状态流细化；4.2 状态集 履行中/结算中/已结算/争议 的账单侧落点，见 CHG-WHO-004）。状态历史不可修改删除（GEN-012）。

**关系**：批发账单 N:1 合同；1:0..1 结算单；1:0..1 争议单；出账后进入税务域开票（CT-007 账单→发票）与应收域账期（账单→应收，AG-09）。

### 1.6 结算单（Wholesale Settlement）

**用途**：对账与结算执行载体（REQ-WHO-004"结算管理"），承载对账结果、结算状态与全程跟踪。

| 属性 | 说明 |
|:-----|:-----|
| settlementId | 结算单标识 |
| billNo / contractId | 关联账单 / 合同 |
| reconciliationResult | 对账结果（账单 vs 客户确认/用量核对，差异清单自动生成，对齐 SET-003 差异清单口径） |
| settledAmount | 结算金额（争议金额冻结后不参与结算） |

| statusHistory | 状态历史（履行中→结算中→已结算，全程可跟踪，GEN-012） |

**状态集**：履行中 / 结算中 / 已结算 / 争议（4.2 基线状态集落点，与 1.5 账单状态联动）。

**关系**：结算单 N:1 合同；1:0..1 批发账单；争议期间置"争议"并冻结争议金额（1.7）。

**用途**：客户用量/账单异议处理载体（WHO-001 例外 / WHO-004），支撑"金额冻结、30 天闭环、留痕"验收（WHO-TC2）。

**用途**：毛利分析载体（WHO-005 / REQ-WHO-005），月度收入−成本分摊=毛利，与账务一致校验。

## 2. 规则实现说明（WHO-001~005，含例外）

> 执行步骤映射：1 批发客户与合同 → 2 用量采集 → 3 批发计费 → 4 门户 → 5 结算 → 6 毛利分析，与本节 2.1~2.6 一一对应。

### 2.1 WHO-001 批发客户与合同（步骤 1）

**实现逻辑**：
1. **客户档案**：批发客户建档复用 CRM 客户主数据（4.3 以 CRM 为准，冲突告警）；本域维护批发专属属性（站点/线路清单、SLA 联系人、门户账号），支撑合同、门户与对账。
2. **合同要素**：批发合同含 客户/产品（批发带宽线路）/价目（合同价、MoU、超量单价、阶梯）/SLA（带宽可用率、故障响应时限）/账期 五要素（WHO-001）；合同引用**签约时价目版本快照**，后续调价不影响存量合同（与 AG-09 账期方案快照口径一致）。
3. **合同状态**：生命周期状态沿用 4.2 Quote/Contract 通用状态（草稿/已签署/履行中/到期/终止）；"履行中"为可出账前提；结算跟踪状态（履行中/结算中/已结算/争议）按 4.2 基线保留于合同维度（语义落点见 CHG-WHO-004）。
4. **变更审批**：合同要素变更（价目/MoU/SLA/账期/产品）均需审批留痕（REQ-WHO-001 验收"合同变更审批"）；变更生成新版本、历史版本保留；生效日不得早于审批通过日，追溯性调整需审批留痕（对齐 SET-001 追溯调整口径）。

**例外与边界处理**：
- **客户用量异议**（WHO-001 例外）：合同履行中客户对用量/账单异议 → 冻结争议金额，按双方确认数据重新出账（落地：争议单 1.7 + 冲账重建，详见 2.5）；合同本身不因异议终止，异议期间合同结算跟踪状态置"争议"。
- **合同到期**：到期前触发"合同即将到期"事件（4.5）提醒大客户经理续约；MoU 未达且合同到期场景见 2.2 例外。

### 2.2 WHO-002 用量采集（步骤 2）

**实现逻辑**：
1. **采集范围**：按合同周期（月度）采集批发线路的峰值带宽/流量/端口占用（3.3.5"采集峰值/流量/端口"），覆盖合同全部在网线路。
2. **完整率**：周期采集完整率 ≥99%（REQ-CL-005 已填基线值 [99]%）；完整率统计口径=完整采集线路数/应采集线路数（口径冻结见 CHG-WHO-002 附注，纳入参数配置）。
3. **缺失处理**：缺失用量标记"待补"（CT-010 失败处理"缺失标记待补"），**不参与当期出账**；补采后重算出账，补采留痕；原始采集记录不可变（对齐 RA-001"重处理不改变原始话单"口径）。
4. **事件发布**：周期采集完成后发布"批发用量已采集"事件（4.5），消费方：计费域（出账）、本域结算（对账）。

**例外与边界处理**：
- **MoU 未达且合同到期**（WHO-002 例外）：合同到期时当期/累计用量低于 MoU → 按合同条款补差（补差金额计算与账务处理口径未定义 → CHG-WHO-007）或进入续约谈判（大客户经理跟进，谈判记录留痕）；补差与正常出账分离、审批留痕。

### 2.3 WHO-003 批发计费（步骤 3）

**实现逻辑**：
1. **计费输入**：合同价目快照（1.3）+ 当期采集用量（1.4，缺失标记"待补"的不参与当期计费）。
2. **计算规则**（WHO-003）：用量 < MoU → 按 MoU 收费（保底）；用量 > MoU → MoU 费 + 超量部分 × 超量单价（按阶梯档位）；**阶梯按月重置**（每月从第一档重新计，不跨月累计）。
3. **账单生成**：周期结束出账生成批发账单（1.5）：账单金额 = MoU 费 + 超额费 + VAT（VAT 口径见 CHG-WHO-003；WHO-TC1 断言账单含税总额 ₱55,000）；出账后账单状态"待客户确认"。
4. **执行归属**：按 CT-010（用量-批发计费：批发→计费），批发域为用量产生方、**计费域为批发计费执行方**；本域 WHO-002 计费规则作为计费域 BIL-003（REQ-BIL-003 批发计费）的规则输入，出账由计费域执行，本域验收差错率 ≤[X]%（REQ-WHO-002 / REQ-CL-005；双头口径见 CHG-WHO-001，避免双引擎）。

**例外与边界处理**：
- **上游采购价变动**（WHO-003 行例外，语义属成本分摊）：成本分摊更新需审批留痕，历史追溯保留口径（落地见 2.6；例外归属行位置见 CHG-WHO-006）。
- **用量缺失**：缺失标记"待补"期间不强行按 MoU 出账（避免误判保底），补采后重算（与 2.2 一致）。

### 2.4 REQ-WHO-003 批发门户（步骤 4）

**实现逻辑**：
1. **功能范围**：批发客户自助查询 用量/账单/历史（REQ-WHO-003），独立批发门户（2.2.5 干系人 14），只读查询、无业务操作。
2. **与核心系统一致**（REQ-WHO-003 验收）：门户为**只读查询视图**，数据源与核心系统同源（查询即读核心已入账数据）；一致性校验（门户展示 vs 核心账单/用量比对）纳入对账任务定期执行（机制细化见 CHG-WHO-008）。
3. **数据隔离**：门户账号绑定客户/站点，站点级数据隔离（对齐 PORT-TC3 企业站点权限），跨客户不可见。
4. **三语**：界面与账单/用量展示按 GEN-007 与 REQ-LAN-001/002（中英菲，缺语言不发布）。

**例外与边界处理**：门户账号停用即时生效（SYS-001 账号管控）；查询范围仅限本客户已入账数据，待补/争议数据展示当前状态（不展示推测值）。

### 2.5 WHO-004 结算管理（步骤 5）

**实现逻辑**：
1. **状态流**（WHO-004）：账单 → **待客户确认** → **已结算**；争议 [30] 天；状态全程可跟踪（REQ-WHO-004 验收；GEN-012 状态历史不可修改删除）。
2. **对账**：批发账单生成后对账（账单 vs 客户确认/用量核对），差异清单自动生成（对齐 SET-003 差异清单口径），对账差错率 ≤[X]%（WHO-TC1B）。
3. **结算执行**：客户确认后账单置"结算中"→ 生成结算单（1.6）→ 审批 → 置"已结算"；结算金额、日期、操作人留痕。
4. **争议处理**：客户异议 → 提交争议单（1.7）→ **争议金额冻结**（不参与结算/收款核销）→ 按双方确认数据重新出账（WHO-001 例外）→ 30 天闭环（时限语义见 CHG-WHO-005）→ 全程留痕（WHO-TC2）。

**例外与边界处理**：
- **争议重新出账**：走冲账重建路径（对齐 CT-007"关账后仅冲账"），新账单重新进入确认流；原账单置"已作废"并关联新账单（可追溯）。
- **争议与应收衔接**：争议期间账单对应应收暂停催收、账龄冻结（对齐 AG-09 异议口径，见 4.3），防止争议期误催收。

### 2.6 WHO-005 毛利分析（步骤 6）

**实现逻辑**：
1. **毛利定义**：批发毛利 = 批发收入 − 上游成本分摊（WHO-005），月度报表（1.10）。
2. **收入口径**：批发收入 = 当期已出账批发账单收入（以计费域账务为准，4.3 账务数据以计费域为准）。
3. **成本口径**：上游采购成本（上游带宽/传输采购）按分摊规则（按合同/线路/用量，配置化）分摊到批发业务；**成本数据源未冻结**（SET 域上游结算合同 REQ-SET-001~005 或独立采购台账 → CHG-WHO-006）。
4. **例外**（WHO-003 行例外）：上游采购价变动 → 成本分摊更新**审批留痕**；**历史追溯保留口径**：已出账月份毛利按原口径核算，追溯调整以调整单形式体现并留痕，不静默修改历史报表。
5. **一致性**：毛利报表与账务一致（REQ-WHO-005 验收 / WHO-TC3）：报表收入=账务收入、成本=账务成本，差异 0 校验；与 RA-003 收入差异分析（计费 vs 收款 vs 实收）衔接，差异可下钻到明细。

**例外与边界处理**：毛利报表生成节奏与计费出账/关账节奏对齐（出账后关账锁定，对齐 REQ-CL-003 关账锁定口径），防止报表与账务短期不一致。

**边界注记**：超量单价单位折算口径基线未明示（用例数据反推为每 10Mbps 一单位）→ CHG-WHO-002 冻结；"含 VAT"为含税总额口径（若为净额则总额 = 55,000 ×（1+税率））→ CHG-WHO-003 冻结；多档阶梯、跨月重置场景纳入 T-2 补充用例。

### WHO-TC1B 结算跟踪（批发账单生成 → 对账 → 差错率 ≤[X]%、状态全程可跟踪）
