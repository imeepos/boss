## 1. 业务对象清单

> 对照 4.2：本域**无既有对象**（4.2 未含 GIS 相关对象），实现级新增支撑对象（见 1.1~1.5，建议补充 4.2，见 CHG-GIS-001）。所有对象带"品牌 + 区域"维度（多层区域树：全国→18 大区→81 省→148 市→~4.2 万 Barangay）。

### 1.1 地址层级（GeoAddress / AddressNode）

**用途**：REQ-GIS-002 层级钻取与 GIS-001 地址录入的作用对象；菲律宾 Barangay 地址体系（Sitio/Purok 为 Barangay 下细分）的载体；也是订单核查（OSS-003 按目标地址定位）、装维上门、故障定位的地理锚点。

| 属性 | 说明 |
|:-----|:-----|
| nodeId | 地址节点标识（全局唯一） |
| level | 层级：大区 / 省 / 市 / Barangay / Sitio-Purok / 街道-小区 / 楼栋 / 单元（8 级地址层级，REQ-GIS-002 钻取链） |
| parentRef | 父级节点（逐级上溯至区域树根） |
| name | 名称（多语种展示，三语：英语/他加禄语/本地语） |
| regionRef / brandRef | 所属区域（区域树节点）/ 品牌（图层维度） |
| locationRef | 坐标引用（楼栋/单元级挂接空间位置，1.2） |
| statRef | 层级聚合统计引用（客户数 / 端口数 / 资产数，逐级汇总） |
| status | 状态（见状态集） |

**状态集**：

| 状态 | 含义 | 触发/解除 |
|:-----|:-----|:-----|
| ACTIVE 有效 | 可用于地址录入与钻取统计 | 层级录入/行政区划调整确认；失效后离开 |
| INACTIVE 失效 | 行政区划调整（Barangay 拆分/合并）后停用，历史地址保留可查 | 调整生效；历史数据不删除 |

**关系**：AddressNode N:1 父节点；Barangay 节点 1:N Sitio/Purok；楼栋 1:N 单元；单元/楼栋 1:0..N 端口挂接（**端口为资源挂接层**，不进入地址录入层级，见 CHG-GIS-003）；地址节点 N:1 区域树节点（前 5 级与区域树共享节点体系，Sitio 及以下为本域地理地址细分）。

### 1.2 空间位置（GeoLocation）

**用途**：REQ-GIS-003 资源按真实位置展示、GIS-003 例外（手工标注）、GIS-004 告警定位的坐标载体；**坐标与底图分离存储**（GIS-002 例外：底图更新不影响业务数据，资源坐标保留）。

| 属性 | 说明 |
|:-----|:-----|
| locationId | 位置标识 |
| objectRef | 关联业务对象（对象类型 + 标识：资产/端口/机柜/杆位/弱电井/CPE/分光器/地址节点） |
| coord | 坐标（地理坐标） |
| coordSource | 坐标来源：GPS 实测 / 现场勘测 / 手工标注 / 近似位置（CHG-GIS-004 精度分级） |
| status | 状态（见状态集） |
| surveyRef | 装维回传记录引用（GIS-001 例外：Sitio 级近似位置→回传更新） |
| regionRef / brandRef | 所属区域 / 品牌 |

**状态集**：

| 状态 | 含义 | 触发/解除 |
|:-----|:-----|:-----|
| VERIFIED 已核准 | GPS 实测/现场勘测，参与"按真实位置展示"验收 | 勘测核准；坐标变更后重新核准 |
| PENDING 待核准 | 手工标注（无 GPS 弱电井/杆位，GIS-003 例外），地图特殊样式展示 | 手工标注；区域负责人/总部核准后转已核准 |
| AWAIT_SURVEY 待回传 | 农村无门牌 Sitio 级近似位置（GIS-001 例外），等待装维回传 | 近似位置标记；装维回传实测坐标并核准后转已核准 |

**关系**：GeoLocation 1:1 业务对象（一对象一坐标，变更留痕）；1:N 勘测回传记录（1.5）；坐标变更发布事件供 AG-06（资产位置回写）与 BI 消费。

### 1.3 光缆路由（CableRoute）

**用途**：REQ-GIS-003 光缆路由展示；消费 AG-06 纤芯/光路数据（OSS-008 纤芯光路管理）叠加地理走向，由杆位/弱电井/管道点序列串接。

| 属性 | 说明 |
|:-----|:-----|
| routeId | 路由标识 |
| cableRef | 光缆段引用（主权 AG-06，本域仅叠加地理走向） |
| nodeList | 途经坐标点序列（杆位/弱电井/管道点，坐标来源含手工标注例外） |
| regionRef / brandRef | 所属区域 / 品牌 |
| status | 状态：规划 / 在用 / 停用 |

**关系**：CableRoute N:1 光缆段（AG-06 主权）；1:N 途经坐标点（GeoLocation）；光缆路由为故障定位（GIS-004）拓扑链路展示的地理图层数据源。

### 1.4 地图图层（MapLayer）

**用途**：REQ-GIS-007 区域/品牌图层化管理；资源图层、光缆路由图层、告警图层、底图的开关与样式配置；总部可切换任意区域视图。

| 属性 | 说明 |
|:-----|:-----|
| layerId | 图层标识 |
| layerType | 图层类型：底图 / 区域图层 / 品牌图层 / 资源图层 / 光缆路由图层 / 告警图层 |
| visibility | 默认显隐（可切换） |
| styleRef | 展示样式（着色/图标/线型，按状态与级别） |
| regionScope / brandScope | 可见范围（区域节点范围 / 品牌范围） |
| permissionRef | 可见性授权引用（GIS-003，复用 AG-01 权限模型） |

**关系**：MapLayer 1:N 可见范围规则（区域/品牌/角色组合）；底图图层与业务坐标图层分离（GIS-002 例外：底图更新仅换底图图层，业务坐标图层不变）。

### 1.5 实现级扩展对象（支撑 REQ-GIS-001/004/006；建议补充 4.2，见 CHG-GIS-001）

| 对象 | 用途与关键状态 |
|:-----|:-----|
| 地图视图/书签（MapView） | 区域经理/总部保存视图（中心点、层级、图层开关、筛选条件）；切换区域一键恢复（REQ-GIS-007） |

## 2. 规则实现说明（GIS-001~004，逐条含例外）

> 规则表 3.2.15 含 GIS-001~004；REQ-GIS-001（地图底座）无对应规则条目 → CHG-GIS-009 建议补充。本节按"规则原文 + 实现逻辑 + 例外"描述业务层面实现，不含技术选型/接口路径。

### GIS-001 地址层级：大区→省→市→Barangay→Sitio/Purok→街道/小区→楼栋→单元；录入必填到 [楼栋] 级

**实现逻辑**：
1. **层级模型**：8 级地址层级（1.1）。前 5 级（大区→省→市→Barangay）与 AG-14 区域树（REQ-REG-004：全国→18 大区→81 省→148 市→~4.2 万 Barangay）**共享同一节点体系**——区域树节点即地址层级节点；**Sitio/Purok 为 Barangay 下细分**（菲律宾行政区划惯例：有 Purok 用 Purok，无则用 Sitio）；街道/小区、楼栋、单元为地理地址细分。全国为地图**根视图**（总部全量场景），层级钻取自大区起（REQ-GIS-002 口径，钻取链起点一并确认见 CHG-GIS-003）。
2. **录入必填到楼栋级**：新装/变更地址录入**强制完成到楼栋级**（含楼栋名/号）；单元级可选（楼栋内多单元场景建议录入）；**端口为资源挂接层**——挂接于单元/楼栋下参与钻取展示（末级展示），不进入地址录入层级（CHG-GIS-003）。
3. **层级钻取与统计**（REQ-GIS-002）：地图按层级**逐级下钻/回退**（每级展示聚合数量：客户/端口/资产）；**数量统计准确**口径 = 该节点下全部子级之和（跨层汇总=各层之和，REQ-REG-004 同口径）；聚合统计与 15 分钟同步批次解耦（统计异步聚合，不阻塞钻取，CHG-GIS-007）。
4. **与业务联动**：订单核查（OSS-003 按目标地址经区域树定位承载节点）复用本域层级定位结果——本域提供"地图定位信息"（AG-11 域定义）；装维上门、故障定位（GIS-004）共用同一地址锚点。

**例外（农村无门牌）**：农村地区无门牌/无楼栋 → 允许 **Sitio 级**标记**近似位置**（坐标来源=近似位置，状态=待回传）；装维上门后**回传实测坐标** → 坐标核准后更新地图与台账（勘测回传记录留痕，1.5 SurveyRecord）。近似位置期间不阻塞订单核查与装维派单（按 Sitio 级承载节点继续可用）；回传更新不影响业务数据（与 GIS-002 例外同原则）。回传时限与未回传处理见遗留事项。

### GIS-002 资产新增/拆除/位置/状态 [15] 分钟反映到地图

**实现逻辑**：
1. **变更来源**：消费 AG-06"资产状态已变更"事件（4.5）与 CT-009 四码关系同步（15 分钟）：资产**新增**（验收入库/领用）、**拆除**（报废/解绑）、**位置**（坐标变更）、**状态**（在用/故障/报废）四类变更驱动地图更新。
2. **[15] 分钟同步**：变更事件进入同步批次，**15 分钟内**地图可见（GIS-TC1 验证）；同步批次与实时查询分离——地图图层用同步视图，资产详情弹窗关键字段（状态）**实时读取兜底**（点击展示 ≤3 秒，CHG-GIS-002）。
3. **地图呈现**：资产按状态着色/图标区分（在用/故障/报废/待核准）；拆除资产从地图移除（历史保留可查，与 AMS-001 解绑/报废留痕联动）；新增资产按坐标出现。
4. **位置变更**：坐标更新事件驱动地图位置移动，移动留痕；坐标状态（已核准/待核准/待回传）样式区分（GIS-001/003 例外联动）。

**例外（底图更新不影响业务数据）**：底图（第三方地图数据）更新/换版**不触发业务数据重投影**——资源坐标与底图**分离存储**（1.2 GeoLocation 独立于底图图层），底图更新仅换底图图层样式，**坐标值保留不变**；底图与业务坐标的叠加偏差按坐标纠偏记录处理（纠偏不改变业务坐标值，仅记录纠偏量，CHG-GIS-006）。

### GIS-003 地图数据权限：区域经理仅本区域，总部全量

**实现逻辑**：
1. **权限模型**：**复用 AG-01 权限模型 + AG-14 区域树**（权限按层继承，REQ-REG-004）：区域经理 = 本区域节点及其全部子级数据可见，**跨区域不可见**（GIS-TC3 验证）；总部/超级管理员 = 全量，可**切换任意区域**（REQ-GIS-007）。
2. **数据可见性 = 区域节点过滤**：地图加载、层级钻取、资源查询、告警定位、关联客户清单展示**全部按用户可见区域过滤**（服务端按区域节点执行，不依赖前端隐藏）。
3. **品牌维度**：品牌图层叠加（REQ-GIS-007 按品牌图层化管理）；品牌可见性与区域权限**组合生效**（多品牌隔离，REQ-BRAND-002）。
4. **与 AG-01 联动**：角色-区域授权由 AG-01 统一维护，本域**消费授权结果**，不另立权限体系（CHG-GIS-008）。

**例外（无 GPS 弱电井/杆位手工标注）**：弱电井/杆位等**无 GPS 信号**位置 → 支持**手工标注坐标**（地图点选/坐标录入，坐标来源=手工标注，状态=待核准）；手工标注坐标经**核准**（区域负责人/总部）后生效，核准记录留痕；待核准坐标地图特殊样式展示，不参与"按真实位置展示"验收口径（CHG-GIS-004）。

### GIS-004 告警一键定位地图物理位置并联动资产/端口/客户/链路

**实现逻辑**：
1. **告警接入**：消费 AG-08"告警已产生"事件（4.5；消费方补充见 CHG-GIS-005）：告警对象（OLT/分光器/端口/设备）→ 经对象标识映射本域空间位置（GeoLocation，1.2）。
2. **一键定位**：地图中心移至告警对象坐标并高亮（GIS-TC2 验证）；告警级别着色区分（严重/主要/次要，与 AG-08 告警分级一致）。
3. **联动展示**：定位后同步展示：①**关联资产**（资产号/状态，AG-06）；②**关联端口**（端口状态）；③**关联客户清单**（经 CT-009 四码关系反查：资产→客户，读路径秒级）；④**拓扑链路**（上联 OLT、光缆路由地理走向，AG-06 光路数据 + 本域光缆路由图层）。
4. **定位快照**：每次定位生成**故障定位快照**（1.5）留痕（告警号、对象、坐标、关联清单、时间），支撑客服工单引用（CT-008 工单内展示定位结果）与事后复盘（REQ-GIS-006 验收"定位准确并展示关联客户"）。

**例外**：规则表无例外项；告警对象**无坐标**（待核准/待回传位置）时，定位到所属地址节点（Barangay/Sitio 级）并标注"位置待核准"（与 GIS-001/003 例外同口径，不臆造精确位置）。

## 3. 用例通过记录（验证设计，未运行）

> 说明：本域无真实运行环境，以下为**验证设计**（Given/When/Then + 预期证据），用于指导 T-2 用例自动化执行阶段；执行结果待回填，未虚构运行结论。

### GIS-TC1 状态联动（资产在用→故障→[15] 分钟地图同步）

**验证场景设计（GIS-TC1-S01）**：
- **Given**：资产 A1（CPE，坐标=已核准，区域 R1）地图显示"在用"；A1 绑定端口 P1（AG-06 台账）。
- **When**：A1 状态变更为"故障"（AG-06 发布"资产状态已变更"事件）。
- **Then**：变更事件进入本域同步批次；**[15] 分钟**内地图上 A1 状态样式更新为"故障"（着色/图标变更）；15 分钟前后地图状态快照对比一致；故障期间地图不误显"在用"。

**预期证据**：同步批次记录（A1、变更时间、批次时间）；地图状态快照（变更前/后）；15 分钟时延测量记录；状态样式更新日志。

**边界注记**：同步窗口内（15 分钟内）地图显示旧状态为规则允许（同步时延口径，GIS-002）；资产详情弹窗实时读状态兜底（点击 ≤3 秒，CHG-GIS-002）。

### GIS-TC2 故障定位（告警对象为分光器→定位物理位置+关联客户清单）

**验证场景设计（GIS-TC2-S01）**：
- **Given**：分光器 S1（坐标=已核准，区域 R1）产生告警（AG-08"告警已产生"，级别=严重）；S1 下挂端口 P1~Pn，经 CT-009 四码关系关联客户 C1~Cn。
- **When**：操作员点击"一键定位"。
- **Then**：地图定位至 S1 物理坐标并高亮；同步展示①S1 资产详情（状态/型号/标签）；②关联端口清单（P1~Pn 状态）；③**关联客户清单**（C1~Cn，经 CT-009 反查，与 AG-02 客户主数据一致）；④拓扑链路（S1 上联 OLT、光缆路由地理走向）；定位快照生成留痕。

**预期证据**：定位记录（告警号、S1、坐标、定位时间）；关联客户清单（与 AG-02 主数据核对一致）；拓扑链路展示记录；故障定位快照（1.5）。

**边界注记**：客户清单准确性依赖 CT-009 四码同步（15 分钟）——告警发生时四码尚未同步的新装客户可能短暂缺失（反查实时/同步 15 分钟口径区分，CHG-AMS-001）。

### GIS-TC3 区域权限（区域经理登录→仅见本区域，跨区域不可见）

**验证场景设计（GIS-TC3-S01）**：
- **Given**：区域经理 M1 授权区域=R1（AG-01 权限模型，权限按层继承）；R1 与 R2 均有资产/客户数据；地图数据权限按 GIS-003。
- **When**：M1 登录浏览地图，尝试访问 R2 数据（钻取/搜索/定位 R2 资产）。
- **Then**：M1 仅见 R1 及其子级数据（地图、层级、资源、告警、客户清单）；R2 数据**不可见**（无数据返回，不展示空壳）；跨区域访问**被拒并留审计记录**；总部账号可切换任意区域并见全量（REQ-GIS-007）。

**预期证据**：M1 会话数据范围（R1 节点及子级）；跨区域访问拒绝记录；总部切换区域操作记录；审计日志。

**边界注记**：权限过滤在**服务端**按区域节点执行（不依赖前端隐藏）；跨区域调配借用资产（OSS-002 例外/REG-003）在地图**归属原区域**展示（归属不变口径，CHG-OSS-009），借入区经理不可见（与台账口径一致）。
