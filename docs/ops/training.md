# 实施培训材料(稳定版 1.0)

> 面向:客户方管理员/运营(Admin)、装机师傅(Worker 端)、客户用户(User 端)三类角色的上手培训。半天课程结构,可按角色拆分场次。

## 1. 课程结构(3.5h + 实操 1h)

| 模块 | 时长 | 对象 | 内容 |
|:-----|:-----|:-----|:-----|
| M1 平台总览 | 30min | 全部 | 订单 12 环节(terms.md 权威清单)、三端边界、状态机总图 |
| M2 Admin 日常运营 | 60min | 管理员 | 登录/角色权限、订单核查与派单、师傅注册审核、资源与四码 |
| M3 Worker 上门作业 | 45min | 师傅 | 扫码绑定、离线缓存、现场证据留存、异常上报 |
| M4 账务与报表 | 45min | 财务/运营 | 账单/发票/话单对账、日报表解读 |
| M5 实操演练 | 60min | 分角色 | 按 M2-M4 场景在验收环境各跑一轮真实流程 |

## 2. 术语表(培训统一口径)

以 `docs/contract/terms.md` 为唯一口径,培训前讲师必须通读;页面列名与字段对照见 `docs/contract/fields.md`,学员疑问以此作答,不即兴发明术语。

## 3. M2 关键路径演示清单(Admin)

1. 登录 → 修改初始密码 → 确认角色菜单与权限一致
2. 师傅注册审核:注册队列 → 实名材料核验 → 通过/驳回
3. 订单核查:新订单 → 地址/资源预占确认 → 指派师傅
4. 全链路时间线:按订单查看 12 环节时间线与异常责任队列

## 4. M3 关键路径演示清单(Worker)

1. 扫码绑定(标签 EPC → 工单)
2. 弱网/离线场景:缓存提交与重试
3. 完工证据:照片/签名留存与上传

## 5. 考核标准

- Admin:独立完成一次「审核师傅 → 核查订单 → 指派 → 查看时间线」闭环
- Worker:独立完成扫码绑定 + 完工证据提交
- 财务:独立解读一份日报表并定位一条对账差异
- 通过标准:流程无人工代偿、无术语误用

## 6. 培训环境与数据

- 使用验收环境(与生产同构),预置演示账号(只读+可重置)
- 培训数据用后清废:走异常责任队列挂账,不混入生产口径统计

## 7. 常见问题(讲师备查)

- 「为什么看不到某菜单」→ 角色权限(menu:* 权限码),找 sysadmin 配置,不是 bug
- 「订单为什么停在某环节」→ 查全链路时间线的责任队列,超时释放/激活失败重试机制见 M1
- 「密码忘了」→ 管理员重置;API key 丢失只能重建,不找回
