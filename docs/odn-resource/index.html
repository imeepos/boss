ODN 基础数据与资源链登记

用途：登记 OLT 至 ODN 端口/分光器的资源关系。基础数据先行，链路在「资源链组装」里逐级带出；未知字段留空，不猜填。

填表说明（导入校验六规则）
层级顺序OCC → ODB → OBD → 一级分光比 → 一级分光端口 → SDB → SBD → 二级分光比 → 二级分光端口。
示例说明基础数据与链路均须为实际资源；示例不计入，正式记录按现场情况填写。
填写原则一行一条实际资源；未知字段留空，不猜填；留空即不入库该字段。
状态原则资源状态留空/规划态一律按 PLANNED 导入，绝不当作已安装、已测试或在用资源。
分光原则总分光比由一级分光比和二级分光比自动计算；填报不一致拒绝该行并报行号。
校验原则层级断链拒绝；枚举未知值拒绝、禁止默认值推断；全列指纹重复去重并报告。
纯静态页：数据仅保存在本机浏览器（localStorage），无网络请求。层级与枚举对齐 docs/contract/fields.md 1.5.12 odn_resource_chain（迁移 000210）与 docs/ODN网络资源表模板.xlsx。
