### 1.1 W1 中场情报追加:文案当 value 的基座防御(2026-09-07 晚,f75f01cd)

W1 域审计在 boss 域实测发现 ≥9 处调用点把显示文案当 value 传给 Dropdown(触发器跌回
placeholder/ariaLabel,102 实证「状态状态」)。按负责人中场契约要求,基座三层防御:

| 层 | 行为 | 依据 |
|---|---|---|
| label 同值兜底 | resolveOptionMatch:精确 value 命中优先;文案恰为某 option label 时按 label 兜底,勾选/键盘落点/高亮全按真实 value 项渲染,选定回写真实 value | pickerCore.test.ts 4 组新用例(共 36) |
| 合成钉选 | 文案双 miss(value/label 域均无)时走既有 withPinnedValue 回显原值,不跌回占位 | 既有 withPinnedValue 用例 |
| warn 留痕 | 两条兜底路径 console.warn('[Dropdown] value 不在 options 值域:…') 每实例去重一次;Phase B 改传真实 value 后自然消失,全站 grep 前缀可盘点存量 | Dropdown.tsx warnedRef 去重 |

边界:MultiSelect 不做 label 兜底(多选勾选集合语义不同),values 传文案按原值回显;
裁定全文见 picker-guide「文案当 value 的存量调用防御」。页面 9 处调用点修正归 W1 Phase B
(本波禁改 pages);现场采样需改动调用方 props,超出本波权限,以纯函数单测 + 门禁佐证。

  大数据量 DialogPicker;存量页 W1-W3 触及时顺势迁移。
