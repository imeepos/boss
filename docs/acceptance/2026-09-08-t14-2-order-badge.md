1. 选定地址 → GET /odn/coverage?addressId:登记记录权威,直接映射 SERVED 可装(绿)/ PENDING 待覆盖(蓝)/ UNSERVED 不可装(红)。

3. 有坐标 → GET /odn/coverage/resolve?lat&lng:SERVED 可装 / UNSERVED 不可装 + 距离。
4. 判定全程 → 评估中(等待态);任一接口失败 → 轻提示(原因可复制 + 可点击重试),**不打断下单主流程**。
5. 地址变更:effect 以序号守卫竞态,只采纳最后一次判定;自动触发,零额外操作。
