# 2026-09-07 工程应付台账与预算里程碑模型（P-INFRA-1 W6,审查 F8/G2）

## 裁定

1. **应付域 AP 归属 ODN 结算域延伸,与 billing 应收域零衔接**：工程应付是「我们对承包商的债」,
   与 billing 域的「客户对我们的债」（应收/账单/缴费）是两套正交口径。应付由 SETTLED 结算单同事务生成,
   数据源与状态联动强绑定 construction_settlements,落 `internal/domain/odn` 避免跨域 import;
   admin 呈现挂 billing 分组仅为 UI 归属（domain-map §2.1 登记,权限码独立 `menu:payables`）。
2. **应付=SETTLED 同事务自动生成,1:1 唯一来源引用**：`construction_payables.settlement_id UNIQUE`;
   金额=结算应付快照（ACCEPTED 后明细锁定不漂移,快照即权威）。VOIDED 冲销=结算单作废同事务
   UPDATE 应付 status+void_reason（原因同源）,作废后重开以新结算单+新应付表达,单据链可回放。
3. **净应付与余额只读派生,不落列**：净应付=应付金额-核减合计,余额=净应付-已付,由子查询/Go 层计算;
   状态 OPEN/PARTIAL/PAID 按流水派生维护（VOIDED 由冲销路径直写）。核减明细与付款流水 append-only,
   「不留列」换取任何时点可从单据链重放推导,杜绝派生值与流水漂移。
4. **部分付款与分期口径**：多次登记付款流水至未付余额耗尽,单笔不超余额（40900）;
   核减后净应付不得低于已付（防超付,40900）。不做退款单/负向付款,冲销后余额可为负如实展示。
5. **发票纯登记**：不联动税局网关（区别于 billing TAX 域）,同应付内发票号唯一防重复登记。
6. **预算执行进度只读派生**：`construction_projects.budget_amount` 可挂可清（NULL=未登记,显示未登记
   而非 0,同 W2 settledCost 口径）;已结算金额=SETTLED 结算单合计,子查询派生禁止直写。
7. **编辑窗口**：预算金额与里程碑清单（增删/改名/计划日）仅项目 PENDING（BUILDING 前）可改;
   里程碑状态标记至项目 ACCEPTED 前（PENDING/BUILDING）;ACCEPTED 后全部锁定。
   登记 terms.md §4。迁移 000218（预算里程碑）/000219（应付台账）/000220（menu:payables）。

## 为什么

- 应付不进 billing 域：跨域只经契约/事件（domain-map §4 规则 2）,若落 billing 包则结算联动
  （同事务生成/冲销）必然横向 import odn 实现,破坏域边界;odn 延伸则联动是域内事务,
  billing 分组呈现用独立权限码即可（permits 先例）。
- 1:1 而非流水式应付：结算单本就是应付凭证,W1 已裁定一项目一张有效结算单,
  应付 1:1 挂接让「来源单据引用」可机械校验（唯一约束）,重开走新单不清历史。
- 同事务生成/冲销而非事件异步：结算确认与应付诞生是同一业务事实拆两面,异步会产生
  「已 SETTLED 无应付」中间态;F8 验收要求 SETTLED 后应付立即可查,事务内是唯一无窗口解。
- 派生而非落列：核减/付款都是低频登记操作,子查询成本可忽略;落列则需要维护
  「列-流水」一致性代码,漂移风险大于收益（W8 出库单状态漂移教训）。

## 放弃了什么

- **应付挂 billing 包 + 事件联动**：换取域边界干净与事务一致;代价是「应付域」在 internal
  层无独立包（呈现层 billing 分组承载语义,域归属以 domain-map §2.1 为准）。
- **退款单/负向付款**：冲销后超付场景只如实展示负余额,纠错走线下;代价是超付 refund
  无系统单据（当前无真实资金通道,不做过度设计）。
- **多轮核减审批/核减单**：核减=一条 append-only 明细（原因必填）,不建审批流;
  代价是核减无复核环节（操作即生效）,由审计留痕兜底。
- **付款计划表**：分期用「多次付款流水」表达,不建计划行;代价是无计划 vs 实际的对比视图
  （当前无此需求,需要时从付款流水聚合即可起步）。
- **发票与付款强绑定**（票到才可付/付清强制开票）：登记彼此独立,代价是无三角对账
  （billing 域 ledger_recon 三角口径不覆盖应付域,需要时再扩）。
