# app.env 固定密钥直接入库

日期：2026-08-18（来源提交序列 04:41 → 04:44 → 04:51）

## 决策

`app.env`（含 JWT 固定密钥与超管引导口令）直接提交进仓库，删除 CI 的 workflow secret 注入步骤，部署零手工配置。

## why

内网私有仓库（gitea 自建），威胁模型不含"仓库可读即边界失守"。此前两轮尝试走仓库 secret 注入（04:41 生成 app.env、04:44 强制 secret），均因部署链路（deploy-runner/compose）凭据装配摩擦失败；secret 方案被实际部署约束否决，属"守卫无对象"式撤回。

## 放弃了什么

- 仓库 secret 注入：部署链路摩擦大、每环境手工步骤多，与"部署零手工"目标冲突。
- 随机兜底密钥：重启即轮换，长期会话全部失效。

## 边界（何时必须重审）

仓库转为公网/多租户托管，或 JWT 密钥需要轮换制度时，本决策立即失效，按 rejected 归档另立新案。
