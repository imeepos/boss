# W3 收口:资源链导入网格归属联动(F2 接通)与资产区域快照回补

- 日期:2026-09-07
- 场景:P-INFRA-1 Phase 2 顺序五 W3 收口(审查 F2):W3 导入只展开箱体设备 odn_device,
  odn_grid/odn_facility 不经导入产生,投资测算与覆盖两链路数据面断层。

## 决策

1. **链行可选携带网格归属**(prv_code/city_prefix/grid_code 三列一体,迁移 000222):
   任一非空即三者必须齐全,缺失拒绝该行(不猜填);(prv,city) 须在 odn_city_code 已登记,
   未登记拒绝该行。不携带归属的链行走 000210 原逻辑,指纹与展开完全一致(存量零变化)。
2. **带归属链行导入同事务联动**:① 备案网格 odn_grid(ON CONFLICT DO NOTHING,既有网格不动);
   ② 建/复用网格锚点设施 odn_facility kind=MH(编码含网格段,规范 4.1 网格分区模式;
   名称=机房名称或「链锚-<首箱体码>」,同链重导/同批多行复用同一锚点;lifecycle 随链行)。
   投资测算网格行设施计数由此非空;覆盖登记挂锚点设施码即进网格行覆盖计数与覆盖页。
3. **机房/OLT/ODF 维持文本引用不升级实体**:模板站点前缀引用(SITE001/SITE001_OLT001)
   非规范设备格式,升级即猜填(000209 红线);实体关联留给城市域主数据既有登记路径。
4. **覆盖登记联动走既有端点,导入不自动造覆盖行**:链无地址映射依据,自动造=编造
   (W4 竣工联动同裁定,adopted 2026-09-07-accept-coverage-linkage);验收脚本显式走
   POST /odn/coverage 挂锚点设施码断言覆盖链路可见。
5. **资产区域快照回补**(W8 遗留①):POST /assets/region-backfill 幂等回补空快照行,
   口径=地址行级节点归属推导(addresses.region_id 或最近非空祖先,000076/000077 同口径);
   地址链全空时存量开户导入批回退该批既有缺省 root 集团(与该批 customers/lo_accounts 同域);
   其余无归属不猜填计 skipped。

## why

- 网格/设施是投资测算(1.5.11)与覆盖归属(1.5.7/1.5.3)两链路数据面的唯一入口,
  导入不产 grid/facility 则导入后两页空转;锚点设施=链的服务落点,编码含网格段
  「设施按编码推导归网格」,与网格分区模式自洽。
- MH(人井)选为锚点类型:网格分区模式 P/MH 是唯一带 grid_code 的设施类型,
  TW/CLS/TBX 市域顺序无网格维度;五类设施语义零改动,锚点仅新增行不扩字典。
- 指纹并入归属:同设备链不同归属是不同资源关系(归属即身份的一部分),
  不并入会「同链不同城」重复导入互相覆盖;无归属行指纹不变保存量幂等。
- 回补走幂等端点而非迁移:一次性数据修复可重跑可观测,down 无需还原语义,
  且未来新导入的空快照行同样可回补(迁移只跑一次)。

## 放弃了什么

- 机房/OLT 升级为城市域实体并挂网格:编码不匹配需猜填,违背 000209 红线;
  升级收益(实体可见)由既有城市域登记路径覆盖,不重复造轮子。
- 导入自动建地址覆盖行:无地址映射依据,造数=编造(与 W4 联动裁定一致)。
- 容量入网格行:W5 裁定「顺序五接通后另行裁定,本期不做」,本收口不动容量模型。
- 迁移式数据回补:不可重跑不可观测,放弃。
