# Sphere Boss 管理后台 App Shell 设计规格

> 继承 `docs/design/visual-design-prompts.md` 全部 Design Token，面板级扩展为完整后台框架。

---

## 1. 整体布局

```
┌──────────────────────────────────────────────────────┐
│  Top Navigation Bar (56px, brand-navy-950)            │
├────────┬─────────────────────────────────────────────┤
│        │                                              │
│ Sidebar│  Main Content Area                           │
│ 240px  │  (scrollable)                                │
│        │                                              │
│        │                                    ┌──────┐ │
│        │                                    │ FAB  │ │
│        │                                    └──────┘ │
├────────┴─────────────────────────────────────────────┤
│  Bottom Info Bar (32px, neutral)                      │
└──────────────────────────────────────────────────────┘
```

### 布局模式

- 经典左侧导航 + 顶部通栏 + 底部状态栏
- 侧边栏可折叠至 64px（仅图标模式）
- 内容区独立滚动，顶栏/底栏/侧栏固定
- FAB 悬浮于内容区右下角，不随滚动

## 4. 通用组件规格

### 4.1 统计卡片

- 4 列网格，间距 16px
- 卡片内边距 20px
- 图标 32px 圆形容器，品牌蓝/金色
- 数值 24px/700，标签 12px
- 趋势箭头：绿色 `#2F8F63` 上涨，红色 `#D94B4B` 下跌

### 4.2 表格

- 表头 12px/500, `#8A96AA`，背景 `#F8F9FB`(亮)/`rgba(255,255,255,0.03)`(暗)
- 行高 44px
- 分割线 `#EFF1F5`(亮)/`rgba(255,255,255,0.04)`(暗)
- 悬停行背景 `#FBF5E8`(亮)/`rgba(213,166,58,0.04)`(暗)
- 分页器右对齐

### 4.3 图表配色

保留品牌色板，扩展数据色：

| 序号 | 色值 | 用途 |
|---|---|---|
| 1 | `#31568F` | 主数据 |
| 2 | `#D5A63A` | 次数据 |
| 3 | `#2F8F63` | 成功/增长 |
| 4 | `#D94B4B` | 告警/下降 |
| 5 | `#5B8FCF` | 辅助数据 |
| 6 | `#E5C985` | 辅助数据 |

## 5. 响应式断点

| 断点 | 侧边栏 | 内容布局 |
|---|---|---|
| ≥ 1440px | 240px 展开 | 最大 1200px 内容区 |
| 1200–1439px | 240px 展开 | 自适应 |
| 960–1199px | 64px 折叠 | 自适应 |
| < 960px | 隐藏，抽屉式 | 单栏，卡片全宽 |
