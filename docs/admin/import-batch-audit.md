# 批量导入入口审计与范围清单

> 2026-09-03｜本期目标：主档列表页直接导入；数据导入中心只追踪记录。
>
> 后续收敛：地址和 Geo 的实际导入入口已迁移至各自业务页，中心页仅保留任务记录。

## 第一批：支持并已迁移

| 页面 | 实体 | 入口 | 依赖/原因 |
|---|---|---|---|
| `/base/account` | 账号 | `account` | 账号主档，依赖角色码；模板使用内置角色码 |
| `/org/company` | 子公司/法人 | `legal_entity` | 法人主档 |
| `/org/department` | 部门 | `department` | 依赖法人 ID |
| `/org/post` | 岗位 | `post` | 依赖部门 ID、角色码列表 |
| `/bss/product` | 产品资费 | `product` | 产品主档，依赖法人 ID |
| `/bss/customer` | 客户档案 | `customer` | 依赖法人、地址、经营区域 ID；需先完成地址与区域主档 |
| `/oss/odn` | 网格/局点/基础设施/核心设备 | `odn_grid` / `odn_site` / `odn_facility` / `odn_device` | 依赖 PRV、城市前缀、网格、局点及设备父级；入口随当前 tab 切换 |
| `/base/address` | 地址层级 | `addr` | 树形主档；父级路径必须先存在 |
| `/base/geo` | 国家与行政区划 | `geo` | ISO/CLDR 基础主档；国家和区划存在父级依赖 |

每个入口复用现有模板、附件选择、Excel/JSON 解析、预览、重复提示、逐行进度、失败行导出和 `POST /import-tasks` 记录登记能力。导入完成后由宿主列表刷新。

## 第二批评估：本期不支持

| 页面 | 结论 | 排除原因 |
|---|---|---|
| 配置模板 | 暂不支持 | 配置下发对象，字段变更可能影响生产下发；需版本/审核/兼容性流程 |
| 官网内容 | 暂不支持 | 内容发布有富文本、封面、分类和发布状态，不是普通行主档导入 |
| 资产台账 | 暂不支持 | 资产编码、入库、部署和四码关联受生命周期及审计约束 |
| 电子标签 | 暂不支持 | 标签绑定和激活属于订单/现场流程，不允许普通批量建档 |
| 端口台账 | 暂不支持 | 端口状态受预占、激活和订单状态机管理 |
| 师傅分组 | 暂不支持 | 分组成员、队长和调度关系需要专门流程，不是独立平面主档 |
| 企业员工 | 暂不支持 | 企业员工涉及企业归属、邀请/审核和权限边界，需专门流程 |

## 全量排除规则

订单、派单、拆机、缴费、支付、出账、发票、欠费、工单、日志、审计、告警、统计、分析等流程或派生数据不支持普通批量导入。API Key、权限、数据范围、短信、推送、认证、存储和备份恢复等敏感或运维配置不支持普通批量导入。

## 已知边界

- 实体导入是前端逐行调用真实创建端点；重复由列表预检和后端约束共同防护，失败行可导出重试。
- 导入任务表当前保存 `imported/failed/detail`，没有独立 `skipped` 列；跳过数在当前会话预览和完成提示中展示，未持久化。
- 任务登记需要 `menu:importer`；实体创建还需要对应实体菜单权限。登记失败不会回滚已完成的实体创建。
- 地址导入与部分旧后端路径的事务/重复错误映射仍需后续服务端专项修复，本批不改变接口语义。
