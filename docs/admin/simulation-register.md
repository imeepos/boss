# 管理后台 · 日常事件模拟清单（角色驱动 · 运维管理场景）

> 目标：从需求出发，以电信工作人员**不同角色**的运维/管理场景为起点，
> 逐轮模拟"日常常见事件"（每轮一个不同事件），每个事件走**完整生命周期**，
> 在系统中逐一找到对应功能点；凡生命周期中出现而菜单未覆盖的触达点，即为需补全的菜单/页面。
> 本文档（含 `menu.js`）即为补全《管理后台》菜单的推导依据与最终落地。

## 〇、角色基线（来源：`migrations/000001_stage1_base.up.sql` 种子，7 角色）

| 角色 code | 角色名 | 职责范围（需求 §四） | 主要触达菜单分组 |
|---|---|---|---|
| `customer` | 客户 | 查本人订单/账单/缴费/报障/资费/在线状态 | 用户端（管理后台不落地，仅下单/报障入口联动） |
| `technician` | 装维师傅 | 领取/接收工单、扫码绑定资产、上报装维结果、异常上报 | 订单与工单 · 四码合一 · 配置下发 |

## 二、逐轮生命周期 ↔ 功能点 ↔ 现状

> 每轮格式：`生命周期环节 → 应触达功能点 → 现状(有/缺)`；"【有】"=菜单已覆盖，"【部分】"=已有页面内的子表/字段级缺口，"【缺】"=需新增菜单。

### S01 新装宽带下单（主线闭环）· 业务运营/客服
下单 → 资源核查 → 端口预占 → 标签预绑定 → 建认证账号 → 预下发 → 派单 → 扫码绑定 → 激活 → 回调 → 更新GIS
- 下单/派单/绑定/激活：order/dispatch 【有】（缺「环节时间轴/耗时/回退重试」明细页 = 【部分】页内）
- 资源核查+预占+释放：resource 【有】，但「预占释放看板/超时批量释放」「扩容申请」无独立入口 【缺】
- 认证账号：【缺】 缺「认证账号/LOID 管理」页（补 `loaccount`）
- 回调：【缺】 缺「激活回调/回调日志」页（补 `callback`）

### S02 订单取消/变更/退订 · 业务运营/客服
取消 → 自动释放端口 → 释放标签 → 订单关闭
- 订单取消/变更：order 【有】（有「跟踪」，无「变更/退订」入口 = 【部分】页内）

### S03 端口预占超时自动/手工释放 · 资源运维管理员
预占计时 → 超时判定 → 自动释放（或手工批量释放）→ 端口回空闲 → 审计留痕
- 超时释放：resource 【有】；缺独立「预占/释放看板」与手工批量释放 【缺】（补 `reserve`）

### S04 欠费停机→缴费→复机（账务联动闭环）· 业务运营/客服 + 计费
欠费达阈值 → 自动停机 → 用户缴费 → 缴费入账 → 复机 → 网络侧生效
- 出账 billing 【有】 / 缴费 payment 【有】 / 欠费停复机 arrears 【有】；缺「停复机执行状态/回执」页 【缺】（补 `stopsrv`）

### S05 客户实名信息变更/补登 · 业务运营/客服
受理变更 → 证件校验 → 更新档案 → 核心客户同步 → 留痕
- customer 【有】；缺「实名认证/证件」字段与「实名核验记录」【部分】页内

### S06 产品/套餐调价（含生效时间）· 业务运营/客服
提调价申请 → 审批 → 设生效时间 → 到达生效 → 历史可查
- product 【有】；缺「价格历史/调价记录」【部分】页内

### S07 客户退订拆机（拆机必扫码）· 业务运营/客服
拆机申请 → 扫码解绑(强制) → 端口释放 → 资产解绑 → 账户停用
- 拆机工单/流程：order/dispatch 未显式承载「拆机单」，扫码强制拦截无独立功能点 【缺】（补 `dismantle`）

### S08 资产入库 · 资产管理员
到货验收 → 建档入库 → 打标签 → 入台账 → 可领用
- 入库：asset 【有】；缺「入库批次/入库单」页 【部分】页内

### S09 资产领用/报废全生命周期流转 · 资产管理员
领用 → 在用 → 故障 → 维修 → 报废（状态机）
- asset 【有】（状态机在资产详情）；缺「生命周期时间轴/流转记录」独立页 【部分】页内

### S10 资产盘点（批量+差异处理）· 资产管理员
盘点 → 扫码/清单核对 → 差异清单 → 逐条处理(确认/修正/上报)
- stock 【有】（建任务冻结快照 → 扫码回填/差异判定 → 差异逐条处置 CONFIRM/FIX/ESCALATE → 全处置完关单 DONE,000156 起全流程闭环）

### S11 光猫故障上报→维修→复测 · 装维师傅 + 资源运维管理员
故障上报 → 状态变更(故障) → 派维修单 → 修复复测 → 回在用
- 故障资产流转 asset 【有】；维修工单 dispatch 【有】；光功率/丢包复测 device 【有】

### S12 扫码绑定不一致（四码校验拦截）· 装维师傅
扫描光猫 → 四码比对 → 与预绑定不一致 → 拦截 → 上报/重绑
- quadlink/check 【有】（对账告警）；缺「扫码绑定异常/拒绝记录」独立页 【缺】（补 `scanlog`）

### S13 四码对账发现冲突→处理→复对 · 资源运维管理员
对账跑批 → 发现冲突 → 定位来源 → 处理(改绑/修正) → 复对通过
- check 【有】（对账与告警）

### S14 OLT 离线/光功率异常告警→通知→恢复 · 资源运维管理员
指标采集 → 阈值越界 → 生成告警 → 通知值班 → 派单处理 → 恢复消除
- device 【有】 / alarm 【有】（确认/派单/消除在 alarm 内）

### S15 配置下发失败重试/回滚 · 资源运维管理员
模板渲染 → 下发 → 失败 → 重试队列 → 仍失败回滚 → 告警
- provision 【有】 / template 【有】；缺「下发日志（失败重试/回滚）」页 【缺】（补 `provlog`）

### S16 存量数据导入（地址/资产/客户）· 系统管理员
导出模板 → 填数 → 上传 → 校验 → 错误核对 → 导入完成
- address 【有】 缺「导入任务/导入错误核对」页；统一「数据导入中心」【缺】（补 `importer`）

### S17 经营分析报告生成与推送 · 经营分析人员
选周期 → 生成报告 → 复核 → 推送 → 归档历史
- analytics 【有】；缺「报告中心/报告历史与推送记录」【缺】（补 `report`）

### S18 扩容决策（投资一张图→扩容申请→实施）· 经营分析人员
热力图 → 识别瓶颈 → 测算投资回报 → 扩容申请 → 实施 → 归档
- gis/analytics 【有】（呈现热力图）；缺「扩容申请单」闭环 【缺】（补 `expand`）

### S19 待替换设备下单→替换 · 资产管理员 + 资源运维管理员
维护清单 → 识别待换 → 生成更换单 → 领新装换回收旧 → 台账更新
- analytics 呈现清单 【有】；缺「设备更换单」闭环 【缺】（补 `replace`）

### S20 端口故障上报/修复恢复 · 资源运维管理员
故障上报 → 端口置故障 → 派修 → 修复 → 回可用
- resource 【有】（状态留痕于端口详情）；缺「端口变更历史」【部分】页内

### S21 角色权限变更即时生效/越权审计 · 系统管理员
改权限 → 快照即时生效 → 越权访问被拒+提示 → 审计留痕
- account 【有】 / audit 【有】（快照即时生效为后端能力，承载于 account）

### S22 AAA 话单丢单/补单（认证计费异常）· 资源运维管理员
话单产生 → 传输丢单 → 对账发现 → 补单 → 复对一致
- aaa 无管理端页面：缺「话单/认证日志」查询页 【缺】（补 `aaalog`）

### S23 客户自助报障→派单→回访（投诉闭环）· 客户 + 业务运营/客服
客户上报 → 生成投诉单 → 分派 → 处理 → 回访 → 关闭
- dispatch 【有】 派单，缺「报障与投诉」独立页 【缺】（补 `complaint`）

### S24 审计追溯（关键操作留痕追责）· 系统管理员
关键操作 → 审计落库 → 多维检索 → 定位责任人 → 追责
- audit 【有】

### S25 五指标看板与端口投资回报核算 · 经营分析人员
指标采集 → 五大指标 → 端口级 ROI → 热力图 → 看板
- analytics 【有】

### S26 缴费渠道对账异常（线上/线下对账）· 业务运营/客服
渠道入账 → 汇总对账 → 差异挂起 → 人工核对 → 平账
- payment 【有】（缴费管理）；缺「缴费渠道对账」独立页 【缺】（补，见结论14）
