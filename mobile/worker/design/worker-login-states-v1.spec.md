# 师傅端 Android 登录页 实现规格（对应 worker-login-states-v1.png）

> 视觉基准：`mobile/worker/design/worker-login-states-v1.png`（本稿为"验证码登录"选中态单屏；密码登录态骨架相同，仅凭据行不同）。
> token 事实源：代码真值 `ui/theme/Color.kt` 优先，其次 `docs/worker/UI-SPEC.md`；与根目录 `designs/login-register-states-v2.spec.md` 同源视觉语言。

## 给前端的实现提示词（可直接复制）

实现 Android（Kotlin + Jetpack Compose，material3）师傅端登录页，高保真还原附图。

- 整体布局：全屏 = 顶部蓝色渐变品牌区（含状态栏安全区）→ 浅灰 `#F6F8FA` 可滚动内容区，悬浮白色圆角卡片（10dp 圆角、卡内 padding 16dp、页边距 16dp）→ 卡片下方居中入驻链接行；页面可垂直滚动，不要求一屏塞满。
- 品牌区（Hero）：渐变 `160deg #0872F4→#0B82F8→#1698FA`；白色半透明圆角方标内线性图标；品牌名"装维全流程 · 师傅端"20sp/700 白；副文案"工单接单 · 现场作业 · 扫码签收"12sp、白 85% 透明度、字距 1sp；两枚半透明白色柔光圆为装饰。
- 分段控件（卡内顶部）：灰底 `#F5F6F8` 圆角槽（10dp、内 padding 3dp），选中块蓝实底 `Primary` 白字 14sp/600，未选中 14sp 灰字 `Muted`；选项"验证码登录 / 密码登录"，切换只换凭据行，骨架不动。
- 表单行：手机号行 = 浅灰 `#F7F8FA` 填充 + `#E7EAF0` 描边 + 12dp 圆角 + 52dp 高 + 左线性图标 + 内置占位文字；验证码行同骨架，右置"获取验证码"13sp 蓝字文字按钮（倒计时态"59s后重发"灰字禁用）；密码行右置眼睛图标切换明文；行间距 8dp；focus 态蓝描边。
- 协议勾选行：圆形勾选框（未勾空心灰边，勾选后蓝实底白勾），触控区 ≥48dp；文案"我已阅读并同意《服务协议》"12sp，《服务协议》蓝色链接跳协议页。
- 主按钮：通栏 46dp 高、10dp 圆角、蓝实底 `Primary`、白字 15sp/600"登录"；未勾协议或加载中禁用置灰；loading 白色转圈。
- 入驻入口：主按钮下方居中一行 12sp 小字"还没有入驻？申请入驻"，"申请入驻"蓝色链接跳入驻页——视觉层级最低，禁止升级为按钮/通栏。
- 色彩：主色 `#1677FF`；Hero 渐变 `#0872F4→#0B82F8→#1698FA`；页底 `#F6F8FA`；卡片白；错误 `#FF4D4F`；文字 `#1F2329` / 次要 `#8C8C8C` / 占位 `#8C8C8C`；分割 `#E8EAED`。以 `ui/theme/Color.kt` 代码真值为准。
- 字体层级：品牌标题 20sp/700；正文与占位 15sp；分段 14sp；辅助 12sp。
- 数据接口（102 部署环境，直连不 mock）：`POST /auth/sms-code {phone}`；`POST /auth/login {phone, mode: sms|password, smsCode|password}`；响应统一信封 `{code,msg,data}`；登录成功取 `data.token` 保存并注册推送后进入首页；错误码文案对齐既有 `friendlyMessage` 约定（40100 凭证错误、40400 账号不存在等）。
- 交互状态：发码（默认可点 → 倒计时灰字禁用 → 可重发；失败提示）；登录（默认 → loading 禁用 → 成功进首页 / 失败红字提示，不白屏）；输入（default / focus 蓝描边）；协议（未勾禁用主按钮 → 勾选启用）；错误提示红色 12sp。

## 注意事项

- 图中文字为 AI 占位渲染，真实文案以 `res/values*`（zh/en/ms 三语）`auth_*` 字符串为准，禁止硬编码中文。
- 装饰性光斑/波浪为 AI 稿氛围元素，实现以现有 `LoginHero` 简化版为准（两枚柔光圆），不追求逐像素一致。
- 本稿仅展示"验证码登录"态；"密码登录"态骨架相同，沿用同一 `AuthForm` 组件体系，禁止另起一套样式。
- 不实现"忘记密码"（后端无对应能力，师傅账号由平台分配）；入驻入口保留现状跳入驻页。
- 状态栏/安全区沿用 `AppRoot` 既有 `safeDrawing` 处理，不再新增。
- 触控与可读性硬标准：输入行 ≥48dp、按钮 ≥44dp、辅助文字 ≥12sp、弱灰文字对比度 ≥4.5:1（占位文字可稍降但需可辨）。
- 与既有实现的关系：本 spec 是 `LoginScreen.kt`/`AuthForm.kt` 现实现的验收基准，逐条核验补齐，不应推翻重写。
